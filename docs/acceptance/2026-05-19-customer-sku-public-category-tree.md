# 验收记录：客户 SKU 公共分类树引用修复

日期：2026-05-19

## 需求
- 在 SKU设置 选择履约客户后，“商品分类 · 客户SKU”开启“是否使用公共商品分类”时，公共分类下的公共 SKU 要随分类显示为只读引用。
- 公共 SKU 可拖拽到客户分类或公共分类中，由后端派生为客户 SKU/客户分类关系；公共 SKU 本身不能直接修改。
- 复制一个公共二级分类后，同一公共一级分类下其他未复制二级分类不能消失。

## 根因
- 前端分类树按“已有客户派生分类优先”过滤公共模板。复制某个二级分类时会同时派生公共父级，导致公共父级被隐藏，未复制的公共兄弟二级分类失去可见父节点。
- 分类树复用了客户 SKU 列表的公共 SKU 开关过滤，导致只开启公共商品分类时，公共分类出来了，但公共分类下公共 SKU 没有随分类树展示。

## 实现
- 新增 `buildSkuContextCategoryTree` 统一生成客户分类树投影：
  - 客户已派生的公共父/子分类作为主节点显示。
  - 未派生的公共兄弟分类合并到同一客户分类树中继续显示。
  - 公共分类下公共 SKU 在分类树中作为只读引用显示；客户 SKU 列表仍按“是否使用公共SKU”独立控制。
- SKU设置 Vue 页面改用该投影函数渲染商品分类树，公共 SKU 行仍通过 `canEditSkuRow` 禁止直接编辑。

## 验证
- RED：`node --test src/lib/product-settings.test.js` 先因缺少 `buildSkuContextCategoryTree` 导出失败。
- GREEN：`node --test src/lib/product-settings.test.js` 通过，覆盖公共分类带出公共 SKU、复制二级分类后未复制兄弟分类保留。

## 结果
- 通过。
