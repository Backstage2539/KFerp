# 2026-05-19 生豆录单绑定熟豆梯度兜底更正

## 状态
- 本记录原本描述“生豆无价时继承绑定熟豆梯度”的临时处理。
- Van 已明确更正：生豆价格不能按熟豆计算，该方案废弃。
- 当前有效验收记录见 `docs/acceptance/2026-05-19-green-bean-list-manual-pricing.md`。

## 新规则
- 生豆 SKU 绑定熟豆只用于取得该熟豆 BOM 的原料组成和 BOM 原料成本快照。
- ERP 录单保存生豆订单时只能读取所选生豆豆单发布快照中的 `green_bean_sale_tiers`。
- 缺少生豆豆单价格时必须拒绝保存并提示缺少生豆豆单价格，不能回退绑定熟豆阶梯价，也不能保存 0 价。
