# 验收记录：产品豆单发布提醒与客户版本号默认递增

日期：2026-05-21

## 范围

- 产品豆单生豆预览区明确提示梯度模板使用 KG 区间，生豆豆单销售单价按元/磅维护。
- 生成豆单抽屉提示必须生成并发布新版豆单后，录单和客户侧才会使用新价格。
- 客户豆单生成时默认版本号从当前客户已发布版本或复制的官方价格源版本递增一小步，不沿用来源版本号。

## 验收点

- [ ] 生豆预览区显示“梯度按 KG，单价按元/磅”。
- [ ] 生成豆单抽屉显示“生成并发布新版豆单后，录单才会使用新价格”。
- [ ] 当前客户已有 `V1` 发布版本时，打开“生成豆单”默认版本号为 `V1.01`。
- [ ] 当前客户没有发布版本但复制官方 `V1` 价格源时，版本号默认改为 `V1.01`。
- [ ] 当前客户已有 `V1.01` 时，默认下一版为 `V1.02`；`V3.0.5` 默认下一版为 `V3.0.6`。
- [ ] 操作员手动修改版本号后，发布仍使用手动输入的版本号。

- 单元测试：`node --test frontend-vue-shell/src/lib/bean-list-pdf.test.js` 覆盖版本递增工具。
- 前端静态测试：`node --test frontend-vue-shell/src/lib/costing-bean-list-version-ui.test.js` 覆盖页面提醒和默认版本号接线。
- API/需求表验证：`go test ./internal/interfaces/http/support -run TestDev306BeanListPublishHints -count=1` 覆盖 PR/DEV/UT/API/REV 种子、手册和验收文档。
