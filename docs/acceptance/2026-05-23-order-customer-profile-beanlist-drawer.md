# PR-345-ORDER-CUSTOMER-PROFILE-BEANLIST-DRAWER

## 验收目标
- 录单/编辑订单不再编辑来源、客户类型和订单类型；这些值只能从客户资料读取并在订单信息中展示。
- 客户资料必须维护客户类型、来源和订单类型，缺少任一项时客户资料保存失败，订单保存也失败。
- 熟豆豆单、生豆豆单和挂耳豆单从订单信息区移到商品明细区的“选择豆单”抽屉，每种豆单都能选择已发布版本；客户没有自定义豆单时使用公共豆单。

## 验收步骤
1. 进入客户档案或录单页“编辑客户”，清空客户类型、来源或订单类型任一字段后保存，确认页面提示必填并拒绝保存。
2. 进入录单页选择该客户，确认订单信息只读展示客户类型、来源和订单类型，页面没有来源/订单类型可编辑下拉。
3. 补齐客户资料后保存客户，再回到录单页选择客户，确认订单保存时后端使用客户资料中的来源和订单类型。
4. 在商品明细标题区点击“选择豆单”，确认右侧抽屉展示熟豆、生豆、挂耳三类已发布豆单选择器。
5. 对没有客户自定义豆单的客户，确认抽屉中对应类型默认展示并使用公共豆单。
