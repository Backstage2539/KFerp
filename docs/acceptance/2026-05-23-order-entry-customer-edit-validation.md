# PR-337 录单客户编辑与字段校验定位

## 需求
- PR-337-ORDER-ENTRY-CUSTOMER-EDIT-VALIDATION：录单选择客户后，“新增客户”旁必须提供“编辑客户”，打开客户资料抽屉并复用销售单客户资料保存逻辑。
- 录单保存时，客户、收款方式、物流、收款凭证或商品明细等必填信息错误/缺失时，除全局弹窗提示外，页面必须滚动定位到对应字段并标红；字段修正后标红自动取消。

## 验收
- 在录单页选择客户后，点击“编辑客户”可打开客户资料抽屉，修改客户名、公司信息、联系信息、默认来源/类型和负责人后保存，当前录单客户保持为该客户。
- 在页面底部点击保存订单，若缺少客户、收款方式、物流公司、物流产品、收款凭证或商品明细，当前视口展示错误弹窗，页面滚动到对应字段并标红。
- 修正被标红字段后，红色边框和字段错误状态自动取消；再次保存继续校验下一个缺失字段或保存成功。
