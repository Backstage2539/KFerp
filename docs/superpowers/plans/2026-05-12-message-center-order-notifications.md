1. 新增消息中心 application/postgres/http 三层，包含事件、投递、已读表和 ERP 通知接口。
2. 将消息中心接入应用路由和权限中间件，ERP 通知接口要求 `orders.read`。
3. 在订单保存、小程序商城下单、客户门户履约下单后发布 `order.created` 消息，payload 携带订单跳转和高亮信息。
4. 订单列表后端新增 `scope` 查询：`mine` 和 `fulfillment`，并传入当前员工 ID。
5. 客户履约客户候选过滤为活跃、批发、已有活跃 ERP 履约绑定的客户；客户履约账户代发列表合并客户门户履约订单。
6. Vue 全局 App 接入消息中心轮询、顶部通知、已读和点击跳转；订单列表增加范围切换、URL 参数同步和状态色。
7. 补充单元测试、API 测试、需求台账、验收清单和操作手册。
8. 运行 `gofmt`、`go test ./... -count=1` 和 `npm run build`，通过后提交、推送并部署。
