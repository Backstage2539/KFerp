# 挂耳产品形态设计

## 背景

现有 ERP 的产品、订单、豆单和成本核算主要围绕熟豆展开。系统里已经有“挂耳”分类和部分挂耳成本参数，但挂耳还不是完整产品形态：不能独立配置 BOM，订单计价仍假设按克重、磅或 kg 计算，豆单也没有独立的挂耳流程。

本次需求新增咖啡挂耳产品。挂耳生产流程是烘焙、磨粉、装袋、装盒。价格计算参考附件 Excel 中“供应售价”S1 开始的挂耳供应价格表。挂耳可以单独出豆单，可以在 ERP 录单、小程序履约客户下单、商城下单中销售。不是每种熟豆都做成挂耳，ERP 上需要可配置挂耳 BOM；挂耳使用的原料是熟豆库存，如果熟豆不足，需要生成上游烘焙需求。

同时，未来还会继续新增产品形态。本次不能只写一套挂耳特例，要建立轻量的产品形态底座。

## 目标

- 新增产品形态：挂耳。
- 挂耳产品作为独立 SKU 管理，有自己的产品设置、BOM、库存、价格、豆单和订单记录。
- 挂耳第一版同时支持按“袋”报价和大货下单，也支持按“盒”下单；默认盒规格为 `10袋/盒`，但系统用配置保存，不写死在订单逻辑里。
- 挂耳价格使用独立价格模板，参考 Excel“供应售价”S1 开始的供应价公式。
- 挂耳 BOM 支持使用熟豆库存作为原料，同时继续消耗滤袋、内膜、盒子等包材。
- 挂耳生产需求能检查熟豆库存；熟豆不足时生成上游烘焙需求。
- ERP 录单、订单列表、小程序履约客户下单、商城下单都能识别挂耳单位和价格。
- 新增挂耳豆单，挂耳产品单独发布、预览和下载。
- 所有用户触发的新增、编辑、发布、下单、生产状态变化都写入操作日志，并能从“操作日志”查看。
- 同步更新相关操作手册和源 Markdown 文档。

## 非目标

- 第一版不做完整公式编辑器。
- 第一版不允许用户自定义任意生产节点和任意脚本公式。
- 第一版不把所有历史熟豆订单迁移成新单位模型，只保证老订单兼容展示和计算。
- 第一版不自动把所有熟豆生成挂耳 SKU。挂耳 SKU 必须显式创建并配置 BOM。
- 第一版不做复杂礼盒组合套装引擎。礼盒、礼袋可以先作为挂耳的包装规格或后续产品形态复用本设计。

## 核心设计选择

推荐采用“轻量产品形态框架 + 挂耳首个落地”的方案。

不推荐把挂耳硬塞进现有熟豆梯度价，因为现有交易计价默认按 `spec_g × qty` 折算为磅或 kg。挂耳按袋、盒、件售卖，如果继续复用克重逻辑，会在录单、客户下单和结算中产生错误。

也不建议第一版做完整制造和公式引擎。当前最稳妥的边界是：产品形态、单位换算、BOM 组件类型、价格模板策略、豆单类型和生产路线可扩展；具体公式策略由后端代码实现，并用参数表配置。

## 产品形态模型

产品增加 `product_kind`：

- `roasted_bean`：熟豆，默认兼容现有产品。
- `drip_bag`：挂耳。

后续产品形态继续增加 code，例如 `capsule`、`cold_brew`、`gift_pack`，但订单、库存、豆单和价格模块不再通过硬编码分类名判断。

产品形态配置包含：

- 名称和状态。
- 默认库存基准单位。
- 可销售单位列表。
- 默认价格策略。
- 默认生产路线。
- 默认豆单类型。
- 是否允许 ERP 录单。
- 是否允许履约客户下单。
- 是否允许商城下单。

第一版产品形态配置可以由后端种子数据维护，不需要做成前端可编辑配置页。产品设置页只需要能选择产品形态并展示对应设置项。

## 产品单位

挂耳的库存和订单需要脱离熟豆克重假设。

挂耳第一版支持：

- `bag`：袋，展示为“袋”，默认 `10g熟豆/袋`。
- `box`：盒，展示为“盒”，默认 `10袋/盒`。

订单行保存：

- 产品 ID。
- 产品形态。
- 销售单位：`bag` 或 `box`。
- 单位数量。
- 单位换算快照，例如 `1盒 = 10袋`、`1袋 = 10g熟豆`。
- 单价。
- 总价。
- 价格来源快照。

这样订单历史不会因为后续修改盒规格而静默变化。

## 挂耳价格模板

附件 Excel 中“供应售价”S1 开始的挂耳供应价表，核心公式为：

```text
挂耳单袋基础成本 =
  熟豆成本/kg × 挂耳熟豆用量kg/袋
  + 挂耳加工成本/袋
  + 挂耳额外成本/袋

挂耳散装供应价/袋 =
  挂耳单袋基础成本 × 数量档倍率
  + 挂耳税费加成/袋

挂耳加包装供应价/袋 =
  挂耳散装供应价/袋
  + 包装材料成本/袋
```

Excel 当前参数口径：

- 挂耳熟豆用量：`0.01kg/袋`。
- 挂耳加工成本：来自生产项目参数。
- 挂耳额外成本：来自生产项目参数。
- 税率：`3%`。
- 供应价数量档：`100 / 1000 / 5000 / 10000 袋`。
- 数量档倍率：`2.2 / 1.8 / 1.6 / 1.35`。
- 加包装成本：挂耳盒子材料成本，Excel 中当前为 `0.2/袋`。

税费加成按 Excel 公式处理：

```text
税费加成/袋 = 挂耳单袋基础成本 × (数量档倍率 - 1) × 税率
```

盒价由袋价换算：

```text
挂耳盒价 = 挂耳加包装供应价/袋 × 每盒袋数
```

第一版价格模板能力：

- 模板类型：挂耳供应价。
- 计价基准：袋。
- 支持散装价和加包装价。
- 支持按袋数量档报价。
- 支持盒单位下单时按 `每盒袋数` 换算价格。
- 价格发布后写入交易价格快照，ERP 录单、履约客户下单和商城下单都只读取已发布价格。

## BOM 与库存

现有 BOM 需要扩展组件类型：

- `material`：物料，例如滤袋、内膜、盒子、标签。
- `finished_product`：成品或半成品，例如熟豆库存。

挂耳 BOM 示例：

- 熟豆成品组件：某个熟豆 SKU，按 `10g/袋` 消耗。
- 滤袋：按 `1个/袋` 消耗。
- 内膜：按配置消耗。
- 盒子：按 `1个/盒` 或按袋摊销消耗。

挂耳 SKU 必须显式配置 BOM 后才能参与生产和挂耳豆单发布。未配置 BOM 的挂耳产品可以保存为草稿，但不能发布价格、不能发布豆单、不能被客户下单。

库存检查顺序：

1. 检查挂耳成品库存是否满足订单需求。
2. 不足时生成挂耳生产需求。
3. 挂耳生产需求检查熟豆组件库存。
4. 熟豆库存不足时生成上游熟豆烘焙需求。
5. 包材不足时生成物料缺口，不自动替代。

## 生产路线

挂耳对用户展示的完整流程是：

```text
烘焙 -> 磨粉 -> 装袋 -> 装盒
```

系统内部拆为两段：

```text
熟豆生产：烘焙
挂耳生产：磨粉 -> 装袋 -> 装盒
```

如果熟豆库存充足，只执行挂耳生产段。如果熟豆库存不足，系统生成或提示上游烘焙工单，再衔接挂耳生产。

生产计划需要按产品形态分派：

- 熟豆缺口进入熟豆生产计划。
- 挂耳缺口进入挂耳生产计划。
- 挂耳计划引用熟豆组件缺口，不能直接把挂耳订单当成生豆烘焙订单。

## 产品设置 UI

产品设置页在 Vue/Vite 前端中扩展，不继续改 legacy HTML 模板。

新增或编辑产品时：

- 选择产品形态：熟豆、挂耳。
- 熟豆产品保持现有字段。
- 挂耳产品显示：
  - 挂耳名称。
  - 可见性。
  - 关联客户。
  - 可销售单位：袋、盒。
  - 每袋熟豆克重，默认 10g。
  - 每盒袋数，默认 10。
  - 挂耳 BOM 配置入口。
  - 挂耳价格模板选择入口。
  - 是否允许履约客户下单。
  - 是否允许商城下单。

产品列表增加产品形态筛选。挂耳产品和熟豆产品都仍然是正式 SKU。

## 挂耳豆单

新增豆单类型：`drip`，展示名称“挂耳豆单”。

挂耳豆单规则：

- 只展示 `product_kind = drip_bag` 且可见、已发布价格的产品。
- 支持按袋显示供应价。
- 支持按盒显示价格，默认显示 `10袋/盒`。
- 价格来源为已发布挂耳价格快照。
- 挂耳豆单发布后保留快照，不随模板或成本参数变化自动改变。

现有熟豆豆单继续保持原规则。

## ERP 录单与订单列表

录单页面选择挂耳产品后：

- 单位选择切换为“袋 / 盒”。
- 数量按所选单位录入。
- 价格按已发布价格快照匹配。
- 大货按袋下单时，数量档按袋数匹配。
- 按盒下单时，系统换算成袋数匹配数量档，再按盒数计算总价。

订单列表显示：

- 产品形态。
- 销售单位。
- 单位规格，例如 `10g/袋` 或 `10袋/盒`。
- 数量。
- 单价。
- 总价。
- 价格来源版本。

后端订单计算必须以保存的销售单位和单位换算快照为准，不能用熟豆的 `spec_g / 454g` 逻辑计算挂耳。

## 小程序履约客户下单

履约客户可见商品接口返回：

- 产品 ID。
- 产品形态。
- 可销售单位。
- 单位规格。
- 已发布价格档。
- 是否允许下单。

客户选择挂耳产品后：

- 可以选择袋或盒。
- 输入对应单位数量。
- 后端根据已发布价格快照计算价格。
- 如果产品没有发布挂耳价格、没有启用下单、没有有效 BOM，则不允许提交。

提交订单后，订单行保存挂耳单位和价格来源快照。

## 商城下单

商城可以展示公开挂耳产品。

第一版商城挂耳价格有两个来源优先级：

1. 如果挂耳产品绑定并发布了商城价格，商城使用商城价格。
2. 如果没有商城价格，不自动回退到供应价，避免把批发价暴露给零售客户。

商城订单行同样保存产品形态、销售单位、单位换算快照、单价和价格来源。

## 权限与审计

必须写操作日志的动作：

- 创建、编辑、停用挂耳产品。
- 创建、编辑、停用挂耳价格模板。
- 发布挂耳价格。
- 发布挂耳豆单。
- 创建、编辑挂耳 BOM。
- ERP 创建或修改挂耳订单。
- 小程序履约客户提交挂耳订单。
- 商城提交挂耳订单。
- 生成挂耳生产需求。
- 挂耳生产状态变化。
- 因熟豆不足生成上游烘焙需求。

审计日志至少记录：

- 操作人。
- 操作时间。
- 操作类型。
- 产品 ID 或订单 ID。
- 关键变更前后值。
- 价格发布版本或豆单发布版本。

## 兼容与迁移

- 现有产品默认设为 `roasted_bean`。
- 现有订单不改写，只按原逻辑展示和计算。
- 新订单行增加销售单位和价格来源快照；熟豆订单可以继续保存克重规格。
- 现有成本参数中的挂耳参数迁移到挂耳价格模板默认参数中，保持当前试算结果可追溯。
- 现有“挂耳”分类可以保留，但产品形态判断以 `product_kind` 为准，不能只靠分类名。

## 测试

单元测试：

- 挂耳单袋基础成本计算。
- 挂耳税费加成计算。
- 100、1000、5000、10000 袋数量档匹配。
- 袋价换算盒价。
- 按盒下单时按袋数匹配价格档。
- 挂耳 BOM 消耗熟豆成品组件和包材组件。
- 熟豆库存不足时生成上游烘焙需求。
- 现有熟豆价格和订单计算不受影响。

API 测试：

- 产品设置创建挂耳产品。
- 挂耳 BOM 创建、编辑和读取。
- 挂耳价格模板创建、发布和读取。
- ERP 挂耳订单按袋下单。
- ERP 挂耳订单按盒下单。
- 履约客户挂耳下单。
- 商城挂耳下单。
- 挂耳豆单发布和快照读取。
- 操作日志能查到关键写操作。

手册：

- 更新成本核算手册，说明挂耳价格模板和 Excel 公式口径。
- 更新物料、库存与 BOM 手册，说明熟豆成品组件和挂耳 BOM。
- 更新订单操作手册，说明挂耳按袋和按盒录单。

- 更新商城手册，说明挂耳商品和价格来源。
- 同步源 Markdown 文档和 Vue/Vite 前端手册入口。

验收：

- 能创建一个挂耳产品，并配置每袋熟豆克重、每盒袋数和 BOM。
- 不是所有熟豆都会出现在挂耳产品中，只有显式创建的挂耳 SKU 可用。
- 挂耳能按袋发布供应价。
- 挂耳能按盒下单，价格按袋价和每盒袋数换算。
- ERP 录单、订单列表、小程序履约客户下单、商城下单都能正确展示挂耳单位。
- 挂耳生产需求能消耗熟豆库存。
- 熟豆库存不足时，系统生成上游烘焙需求或明确展示缺口。
- 挂耳豆单与熟豆豆单分开发布，已发布快照不被后续参数修改影响。
- 所有用户触发的业务写操作都能在“操作日志”看到。
