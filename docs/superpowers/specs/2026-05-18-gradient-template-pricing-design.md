# 梯度模板与豆单价格来源设计

## 背景

产品设置已有 SKU 归属、商品一二级分类、成本试算、价格发布和豆单发布。现有商用熟豆梯度主要来自固定规则和快速成本参数，操作员难以按分类维护不同梯度，也难以解释某个豆单价格为什么变化。

本次设计将商用批发梯度从固定规则升级为“梯度模板 + 二级分类绑定 + 价格来源解释”。第一版不做产品级覆盖，不做完整公式编辑器。

## 目标

- 支持新增、编辑、停用多个梯度模板。
- 每个模板统一一个展示单位，例如元/磅或元/kg。
- 模板内每档配置自定义区间名、系统克重区间、利润率和排序。
- 二级分类可选择一个梯度模板，分类下产品全部继承。
- 成本试算和未发布豆单预览按分类模板实时计算。
- 录单、客户下单等交易价格只有管理员发布价格后才生效。
- 已发布豆单保留发布时快照，不随模板或快速成本参数静默变化。
- 豆单价格来源解释必须展示产品成本、快速成本参数、模板档位和最终价格；解释内参数调整只做临时试算，不保存设置。

## 非目标

- 第一版不做单个产品覆盖模板。
- 第一版不允许同一模板内各档使用不同展示单位。
- 第一版不提供任意公式编辑器。
- 第一版不自动改写已发布豆单和交易价格。

## 功能边界

### 梯度模板

模板字段：

- 名称。
- 状态：启用、停用。
- 展示单位：`lb`、`kg` 或 `unit`。一个模板只能选择一个展示单位。
- 取整规则：第一版采用现有四舍五入到整数价格。
- 档位：
  - 自定义区间名，仅用于豆单和页面展示。
  - 最小总克重，必填。
  - 最大总克重，可为空表示无上限。
  - 利润率，必填，非负。
  - 排序。

系统匹配永远按 `规格克重 × 数量` 落入克重区间，不能依赖区间名文案。

### 二级分类绑定

- 一级分类不绑定模板。
- 二级分类可选择一个启用模板。
- 分类绑定模板后，分类下产品在试算中继承该模板。
- 未绑定模板的二级分类继续使用现有默认成本梯度规则，保证老数据兼容。
- 停用模板不删除历史配置；引用停用模板的分类显示风险提示，试算可继续读取最后配置，但不能新选该停用模板。

### 价格计算

价格计算分三层：

1. 产品成本：生豆成本、BOM、出成率。
2. 快速成本参数：kg/lb 换算、小批量/大批量生产成本、批发包装成本、产品损耗、税费等。
3. 梯度模板：克重区间、利润率、展示单位、取整。

模板计算仍复用现有成本公式：

- `熟豆成本 = 生豆成本 / 出成率`
- 小批量档基础成本使用小批量生产成本；较大档基础成本使用大批量生产成本。
- `梯度 kg 价 = 基础成本 × (1 + 利润率) + 批发包装成本 + 产品损耗 + 税费`
- 元/磅展示时按 `kg 价 × kg_to_lb_factor + 1` 延续现有换算逻辑。
- 元/kg 展示时直接使用 kg 价。
- 发布到产品价格梯度时，保留 `spec_g`、克重对应的 `min_qty_units/max_qty_units`、展示单位价格和折算 `price_per_lb`，保证录单和客户下单仍由后端发布结果驱动。

## 价格来源解释

从价格试算行或豆单预览的梯度价格打开解释抽屉。

解释内容：

- 商品名称、分类、模板名称、档位名称。
- 命中逻辑：档位克重区间，以及示例总克重。
- 公式节点：
  - 生豆成本。
  - 出成率。
  - 熟豆成本。
  - 小/大批量生产成本。
  - 包装成本。
  - 损耗。
  - 税费。
  - 档位利润率。
  - 展示单位换算。
  - 取整前价格和最终价格。
- 参数来源：
  - 产品/BOM。
  - 快速成本参数。
  - 梯度模板。

抽屉内可调整参数做临时试算，变化只影响当前解释视图，不保存到快速成本参数或梯度模板。正式保存仍从对应设置入口保存，并且交易价格仍需发布后生效。

## UI 设计

产品设置页增加“梯度模板”工作区：

- 模板列表展示名称、展示单位、档位数、启停状态、引用分类数。
- 编辑区维护模板基本信息和档位表。
- 二级分类行展示当前绑定模板，并提供模板下拉选择。

价格试算和豆单预览：

- 商用批发梯度旁增加“来源”按钮。
- 来源抽屉展示公式链和临时试算。
- 修改模板或快速成本参数后，未发布预览实时变化；页面提示“交易价格需发布后生效”。

## API 与持久化

新增持久化：

- `pricing_gradient_templates`
- `pricing_gradient_template_tiers`
- `product_categories.gradient_template_id`

新增 API：

- `GET /api/pricing-gradient-templates`
- `POST /api/pricing-gradient-templates`
- `PUT /api/pricing-gradient-templates/:id`
- `POST /api/pricing-gradient-templates/:id/deactivate`
- `POST /api/product-settings/categories/:id/gradient-template`
- `POST /api/costing/price-explanation`

`GET /api/product-settings` 需要返回分类绑定的模板 ID 和模板列表，供产品设置页一次性渲染。

## 权限与审计

- 模板新增、编辑、停用、分类绑定模板属于产品设置写操作。
- 后端记录审计日志：模板创建/编辑/停用、分类模板绑定。
- 价格来源解释是读取和临时试算，不写审计。

## 测试与验收

单元测试：

- 模板档位按克重区间匹配，区间名不参与匹配。
- 模板统一展示单位，按元/kg 或元/磅生成价格。
- 未绑定分类继续走默认规则。
- 价格来源解释包含快速成本参数、模板利润率和最终价格。

API 测试：

- 模板 CRUD 和停用。
- 二级分类绑定模板。
- 产品设置返回模板和分类绑定。
- 价格来源解释接口返回公式节点。

手册：

- 更新成本核算手册。
- 更新物料、库存与 BOM 手册中的产品设置章节。
- 同步 `orderapp-remote/docs` 副本和手册入口。

验收：

- 产品设置能新增模板并配置多个克重档。
- 二级分类能绑定模板。
- 分类下产品试算按模板变化。
- 价格来源能解释快速成本参数和模板档位。
- 临时试算不保存系统设置。
- 发布前交易价格不变；发布后交易价格按新梯度生效。
- 已发布豆单保持快照。
