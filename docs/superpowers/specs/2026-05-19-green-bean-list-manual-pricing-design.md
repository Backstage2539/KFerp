# 生豆豆单手工定价设计

## 背景

岩师傅的“兰卡拼配生豆”在录单时没有价格。上一轮修复把生豆无价场景临时兜底到绑定熟豆的阶梯价，但这不符合业务口径：生豆绑定熟豆只表示绑定该熟豆当前有效 BOM，不表示继承熟豆销售价格。

本设计以“生豆豆单是生豆交易价格唯一来源”为准，重做生豆豆单生成、编辑、发布和录单取价边界。

## 目标

1. 生豆 SKU 绑定熟豆 SKU 后，通过熟豆当前有效 BOM 获取原料组成、比例和 BOM 保存的原料成本快照。
2. 生豆豆单生成时只计算 BOM 成本参考，不套熟豆出成率、烘焙加工、包装、损耗、税费、利润率或熟豆销售梯度。
3. 生豆豆单档位来自 SKU 所属分类绑定的梯度模板，用户只修改每个档位的销售价。
4. 生豆豆单手工价格只保存到本次草稿和发布版本快照，不回写 SKU、BOM、物料或梯度模板。
5. 录单按产品形态分别选择熟豆、生豆、挂耳豆单版本，默认最新可用版本；客户没有专属豆单时使用公共豆单。
6. 生豆交易行只能按选中生豆豆单版本取价，缺价时报错，不再使用绑定熟豆阶梯价兜底。

## 非目标

1. 不重做熟豆、挂耳现有定价公式。
2. 不引入库存批次加权价作为生豆豆单成本来源。
3. 不给生豆 SKU 增加长期销售价字段。
4. 不允许在生豆豆单里修改档位区间；档位区间仍由梯度模板维护。

## 生豆价格来源

生豆 SKU 的 `green_bean_bom_product_id` 指向一个熟豆 SKU。系统通过这个熟豆 SKU 查找当前有效 BOM。

生豆豆单生成时读取 BOM 中的：

- 原料行
- 原料比例或用量占比
- BOM 保存的原料成本快照

拼配生豆的成本参考按 BOM 比例加权：

```text
成本参考(元/kg) = Σ(原料成本快照(元/kg) × 原料比例)
```

单品生豆也从绑定熟豆 BOM 读取对应原料成本快照，避免被物料档案当前价或库存批次变化影响。

生豆没有自动售价公式。系统只把成本参考按梯度模板单位换算成默认销售价：

```text
元/kg   = 成本参考
元/磅   = 成本参考 × 0.454
元/100g = 成本参考 × 0.1
元/227g = 成本参考 × 0.227
元/250g = 成本参考 × 0.25
```

用户可以逐档修改销售价。发布后保存修改后的价格快照。

## 生豆豆单编辑流程

产品豆单选择“生豆豆单”并生成预览时：

1. 公共豆单读取公共可见生豆 SKU。
2. 客户豆单读取该客户自己的生豆 SKU，以及该客户开启引用的公共生豆 SKU。
3. 每个生豆 SKU 展示 SKU 名称、生豆类型、绑定熟豆、BOM 状态、成本参考、梯度模板名称、模板单位和档位价格。
4. 档位区间来自分类绑定的梯度模板。
5. 每个档位销售价默认等于 BOM 成本参考按模板单位换算后的值。
6. 用户修改销售价后，保存草稿或发布版本。

绑定熟豆没有有效 BOM、BOM 已失效或分类没有梯度模板时，该 SKU 必须显示缺配置状态；发布时不能把它作为有效价格静默发布。

发布版本内容必须包含：

- SKU ID 和名称快照
- 生豆类型快照
- 绑定熟豆 ID 和名称快照
- BOM 来源和成本参考快照
- 梯度模板名称、展示单位和档位区间快照
- 每个档位的最终销售价

后续 BOM、物料、库存批次或梯度模板变化，不影响已发布版本。

## 录单版本选择和取价

录单选择客户后，系统分别准备三类豆单版本：

- 熟豆/商用豆单版本
- 生豆豆单版本
- 挂耳豆单版本

每类默认选择最新可用版本。客户有自己的对应豆单时使用客户豆单；客户没有对应豆单时使用公共豆单。用户可以选择历史版本。

混合订单中，每个订单行按自己的产品形态读取对应豆单版本：

- 熟豆行读取熟豆/商用豆单版本。
- 生豆行读取生豆豆单版本。
- 挂耳行读取挂耳豆单版本。

保存订单时，订单行必须记录该行使用的 `bean_list_publication_id`、`bean_list_version_no`、价格档位和价格来源快照。订单头可以继续保留兼容字段，但真实取价和追溯以订单行为准。

生豆行如果在选中的生豆豆单版本中找不到对应 SKU、规格和数量的价格档，保存接口必须返回缺少生豆豆单价格的错误。系统不得用绑定熟豆阶梯价兜底，也不得静默保存 0 价。

## 需要撤回的旧逻辑

1. 删除录单表单 API 中“生豆无价时返回绑定熟豆梯度”的逻辑。
2. 删除保存订单中“生豆无价时回退绑定熟豆梯度”的逻辑。
3. 删除交易价格来源 `green_bean_bound_roasted_tier`。
4. 更新手册和验收标准，明确生豆交易价只来自生豆豆单版本。
5. 把上一轮兜底测试改成反向测试：没有生豆豆单价时必须缺价失败。

## 验收标准

1. 岩师傅“兰卡拼配生豆”录单前，需要先发布岩师傅或公共生豆豆单；录单默认选择最新生豆豆单版本并从该版本取价。
2. 生豆 SKU 即使绑定熟豆且熟豆有启用阶梯价，只要选中的生豆豆单版本没有价格，录单保存必须失败并提示缺少生豆豆单价格。
3. 生豆豆单预览展示 BOM 成本参考和模板档位，每个档位销售价默认按模板单位从成本参考换算而来。
4. 用户修改生豆豆单档位价格并发布后，录单按发布版本快照保存订单行价格。
5. 熟豆、生豆、挂耳混合订单中，每一行记录自己的豆单版本和价格来源。
6. 修改 BOM、物料档案、库存批次或梯度模板后，已发布生豆豆单版本和历史订单价格不变。
