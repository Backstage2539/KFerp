# KFerp 通用制造模型设计

## 核心模型
- SKU：销售、库存、生产对象，支持公共 SKU、客户 SKU、产品形态和行业字段模板引用。
- BOM：物料组成和理论投入产出关系。底层兼容 `product_bom.yield_rate`，用户侧按预期损耗率/预期产出率理解。
- 工艺模板：某个 SKU/BOM 版本的制造方案，包含工艺路线、默认设备、默认工时、关键参数和行业字段模板。
- 工序：工艺路线中的步骤，例如烘焙、裁剪、缝制、去皮、包装。
- 工单：某次生产任务，冻结当时 SKU、BOM、工艺模板、工序路线和关键参数。
- 工序卡：工单中每个工序的执行记录，记录实际投入、实际产出、实际损耗、设备、人员、质检和异常原因。
- 生产批次/成品批次：最终库存和追溯链。

## 损耗口径
- BOM 层：预期损耗/预期产出率，用于报价、成本、计划投料。
- 工艺模板层：可按工艺条件覆盖默认损耗，例如烘焙度、裁剪方式、去皮方式。
- 工序层：定义该工序是否记录损耗。
- 工序卡层：记录实际投入、实际产出和实际损耗。
- 工单/生产日志层：汇总整单实际损耗和实际产出。
- 成本层：理论成本取 BOM，计划成本取工单快照，实际成本取生产日志和工序卡。

## 系统边界
- 不把咖啡字段写死到主模型；咖啡、服装、鲜果差异通过行业字段模板和工序参数 JSON 承载。
- 工艺模板不替代 BOM；BOM 解决“用什么物料、理论投入产出”，工艺解决“怎么生产”。
- 工艺模板不替代工序；工序是路线步骤，工艺模板是一组步骤和参数的方案。
- 工单必须快照化，避免后续修改 BOM/模板影响历史生产。
