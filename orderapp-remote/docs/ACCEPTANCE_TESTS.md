# orderapp 验收清单与测试用例（截至 2026-02-13）

> 目标：给日常验收/回归测试用。每次上线前按此清单抽测。

## A. 录单（/app/order）

### A1. 客户选择与联动
- [ ] 客户下拉仅显示 active=true 的客户（停用客户不出现）。
- [ ] 客户选择框支持客户名、拼音、首字母模糊搜索。
- [ ] 选择客户后：来源、订单类型自动填充并**覆盖**原值。
- [ ] 新录订单默认付款状态为已付款、发货状态为未发货。
- [ ] 录单页点击“新增客户”从右侧打开抽屉，不离开当前订单；粘贴“姓名/电话/地址”后可自动识别并填充，默认来源为微信、订单类型为批发，保存后自动选中新客户。

### A2. 明细输入（规格 + 件数）
- [ ] 选择商品后：规格默认该商品第一个价格梯度的规格。
- [ ] 规格下拉包含 36g、80g、100g、227g、454g、500g、1000g、2.5kg。
- [ ] 数量(件)只能按整数处理（输入小数时，系统行为符合预期：建议前端拦截/或后端拒绝；以实际上线行为为准）。
- [ ] 总重量实时显示：xxx g / yy lb。

### A3. 自动匹配阶梯价
- 用例：选择一个有阶梯价的商品。
  - [ ] 页面展示该商品所有规格/数量梯度和单价。
  - [ ] 规格 454g、数量 1：能算出单价/小计。
  - [ ] 规格 454g、数量 10：匹配到更高档（若存在）。

### A4. 低于最低档（非阻断）
- 用例：规格 50g、数量 1（总 lb 很小）。
  - [ ] 页面出现“低于最低档”的提示。
  - [ ] 仍然可以保存订单。
  - [ ] 默认按最低档单价计算。

### A5. 手动单价覆盖
- 用例：对同一行选择“手动单价”，输入元/磅。
  - [ ] 小计按手动单价重新计算。
  - [ ] 保存后订单金额与页面一致。
  - [ ] 点击恢复自动价后，按当前商品/规格/数量重新匹配梯度价。

### A6. 保存
- [ ] 保存后跳转/提示“已保存订单号”。
- [ ] 保存订单时不进行快递处理，不生成快递录单 Excel 下载入口。

---

## B. 订单列表（/app/orders）

### B1. 查询/筛选
- [ ] 支持关键字搜索。
- [ ] 支持日期范围筛选。
- [ ] 作废筛选：默认不显示作废单，可切换查看作废/全部。

### B2. 列表内联编辑 + 审计
- [ ] 修改收款状态/发货状态/备注后能保存成功。
- [ ] 修改会写入审计日志（/app/audit 可查询到）。

### B3. 生产完成订单发货处理
- [ ] 点击“只看生产完成”后列表筛选到生产完成订单。
- [ ] 只有生产完成订单可以勾选发货处理。
- [ ] 勾选一个或多个订单后，可生成快递录单 Excel 并展示下载入口。
- [ ] 下载的 Excel 使用服务器快递模板，收件人来自客户档案，寄件人默认来自发货人设置的默认寄件人。
- [ ] 本次生成前可以选择默认寄件人；已勾选订单中的某几单也可以单独选择寄件人，Excel 对应行使用对应寄件人资料。
- [ ] Excel 中包裹件数为 1，托寄物为茶叶，重量为 0.1kg，备注包含对应订单明细但不包含单价和小计。
- [ ] 生成 Excel 后页面展示发货批次号。
- [ ] 回填快递单号后，订单列表显示该单号，发货状态为已发货。
- [ ] 上传顺丰寄件列表回传 Excel 后，系统按备注中的订单号回填对应订单快递单号，并将发货状态更新为已发货。

### B4. 发货人设置
- [ ] 发货人设置页面展示寄件人列表。
- [ ] 可以新增/编辑寄件人，并设置一个默认寄件人。

## E. 客户档案（/app/customers）

### E1. 列表内编辑
- [ ] 客户名/联系人/电话/地址可在列表直接修改并保存。
- [ ] 客户公司名称、公司地址、联系电话可在客户录入/编辑界面保存；公司名称为空时销售单默认使用客户名。
- [ ] 默认来源、默认订单类型可在列表直接修改并保存。

### E2. 一键复制发货地址
- [ ] 点击“一键复制发货地址”后，剪贴板内容为：
  - 姓名：xxx（联系人为空则用客户名）
  - 电话：xxx
  - 地址：xxx

### E3. 删除（停用）
- [ ] 点击“删除”二次确认。
- [ ] 删除后客户被停用（active=false），录单客户下拉不再出现。
- [ ] 删除动作写入审计日志。

### E4. 快速粘贴解析（/app/customers/new 或 /:id）
- 用例：粘贴
  - `姓名：张三\n电话：13800138000\n地址：上海市...`
  - [ ] 一键解析后能填充联系人/电话/地址。

## H. 用户权限与账号（/vue-shell?view=userPermissions）
- [ ] 管理员能为员工启用/停用登录。
- [ ] 停用员工无法密码登录或短信登录。
- [ ] 停用员工已有 Bearer token 不能继续访问接口。
- [ ] 用户权限页对未设置密码的员工显示“设置密码”，对已有密码的员工显示“重置密码”。
- [ ] 管理员设置或重置密码后，员工可以使用新密码登录。
- [ ] 用户名或手机号密码登录成功后自动进入系统，页面 API 请求携带 Bearer token。
- [ ] 登录成功后的首屏能直接看到默认展开的功能菜单，不需要刷新页面才出现功能入口。
- [ ] admin 角色账号登录后能看到全权限菜单。
- [ ] 点击顶部“退出”后回到登录页，当前 token 被清除且会话被注销；直接打开系统地址不能绕过登录。

## I. 生产制造（/vue-shell?view=producePlan / produceRunning / qualityInspections）

### I1. 物料需求计划
- [ ] 在生产计划选择商品并生成计划后，点击“物料需求计划”。
- [ ] 表格展示物料需求、WIP 库存、WIP 可用、建议领到 WIP、已占用 WIP、原料仓库存、缺料量和采购建议。
- [ ] 接口 `/api/produce/material-plan` 返回 `required_g`、`wip_g`、`available_g`、`wip_transfer_suggestion_g`、`reserved_g`、`raw_g`、`shortage_g`、`purchase_suggestion_g`。

### I2. WIP 占用
- [ ] 开始生产后，工单建立 WIP 软占用。
- [ ] 另一个工单开始生产时，不能重复占用已被前一个工单占用的 WIP 库存。
- [ ] 取消生产后，相关 WIP 占用释放。
- [ ] 生产工单列表展示 WIP 已占、已耗和剩余占用。
- [ ] 仓库库存点击“WIP占用”后，可按工单查询占用、调整占用克重、释放废弃工单占用。
- [ ] 接口 `/api/produce/wip-reservations`、`/adjust`、`/release` 可返回/处理 WIP 占用。

### I3. 部分完工
- [ ] “生产中”每一行直接展示并可编辑投料(g)、成品件数和余料(g)。
- [ ] 初始未编辑时，实际出品率显示 BOM 出品率；修改投料或成品数后，实际出品率实时按 `成品总克重 / 投料数` 更新。
- [ ] 在“生产中”填写本次产出，勾选“部分完工（保留剩余）”。
- [ ] 提交后，本次产出进入成品仓，本次消耗从 WIP 扣减。
- [ ] 剩余需求和剩余投料仍保留在“生产中”，后续可继续完成。

### I4. 生产质检
- [ ] 进入“生产质检”，可新增原料、生产工单或成品批次质检记录。
- [ ] 结果支持通过、待处理/待定、不合格/不通过；把工单质检改为“不通过”或“待定”时不会再提示 `scope, reference_no and result required`。
- [ ] 质检列表可按范围和结果筛选。
- [ ] 工单质检为“待处理”或“不通过”后，对应 `FP-...` 成品批次显示质检状态；原料批次、WIP 仓库存和成品批次列表也显示同一状态。
- [ ] 冻结批次不能继续领料到 WIP、不能被生产完工扣料，也不能被成品出库/转仓误用。

### I5. 生产验收
- [ ] 进入“生产验收”，能看到仓库、原料库存、WIP、生产工单、WIP 占用、生产日志、质检和成品追溯检查项。
- [ ] 接口 `/api/produce/acceptance-smoke` 返回检查项、状态、数量、说明和目标入口。
- [ ] 仓库相关检查项点击“打开”后进入对应仓库和库存类型，例如 WIP 检查项进入 WIP 在制仓，不停留在“全部仓库”。
- [ ] 生产手册同步说明生产验收、建议领到 WIP、WIP 占用调整/释放的操作。

### I6. 仓库批次追溯
- [ ] 在“仓库库存”输入 `FP-...` 成品批次，可看到成品、工单、生产日志和消耗原料批次。
- [ ] 输入 `MB-...` 或 `LEGACY-MAT-...` 原料批次，可看到该原料批次的供应/期初说明和当前仓库位置。
- [ ] 批次追溯详情展示质检状态；待处理或不通过批次以冻结状态提示。
- [ ] `LEGACY-MAT-...` 页面说明这是系统升级时按旧物料库存生成的期初批次，点击查询不再提示 `batch not found`。

## J. 豆单发布（/vue-shell?view=costing）
- [ ] 生成豆单抽屉默认仍为“棵凡官方豆单”，发布后官方公开链接正常访问。
- [ ] 切换为“我的客户豆单”后，可选择一条官方已发布豆单作为“复制官方价格来源”。
- [ ] 客户豆单发布时保存官方价格来源和自己的历史样式来源。
- [ ] 客户豆单发布后，内容和价格以发布时快照为准；后续官方豆单更新不会自动改写该客户豆单。
- [ ] 管理员账号可以发布/撤回豆单；客户账号看不到发布/撤回入口，保存修改后只能生成 PDF 下载。
- [ ] 客户账号直接调用发布/撤回接口会被拒绝，保存草稿接口返回该客户自己的 owner。

## K. 销售单客户信息（/vue-shell?view=salesOrder）
- [ ] 订单列表点击某行“销售单”后，在当前页面打开销售单抽屉，不跳走也不丢失列表筛选和分页。
- [ ] 销售单抽屉内点击“销售单设置”后，打开设置抽屉，可维护说明、收款方式、收款码和公章。
- [ ] 进入订单销售单页面后，点击“客户信息”会从右侧打开客户编辑抽屉。
- [ ] 抽屉可保存客户公司名称、公司地址、联系电话；保存后页面摘要同步刷新。
- [ ] 未设置销售单公司名称且客户公司名称为空时，生成销售单不会再报 `company_name required`，PDF 公司名使用客户名。
- [ ] PDF 中展示客户公司、联系电话和公司地址。
- [ ] 页面先展示销售单预览，确认生成按钮在预览加载后才可点击。
- [ ] 刷新预览不会新增销售单历史版本；确认生成后才新增一个版本。
- [ ] 历史版本下载和下载最新版都返回 PDF，不再出现 `invalid document id`。
- [ ] 公司名称在“公司设置”中维护，销售单设置页不再维护公司名称。
- [ ] 销售单预览展示收款码图片、公章图片、多行收款方式和多行个性化说明；下载 PDF 与预览关键信息和版式一致。
- [ ] 销售单设置页和销售单预览页都可拖动公章位置，销售单设置页可调整公章大小，下载 PDF 中公章盖在公司名称附近且不拉伸变形。
- [ ] 销售单设置页可维护公账收款户名、开户行、账号；保存后预览和新生成 PDF 展示该公账信息。
- [ ] 销售单设置页点击“去除背景”后，当前公章变为透明 PNG，红色印章内容保留。
- [ ] 多个收款码在销售单预览和下载 PDF 中并排展示，并与收款方式、公账信息、说明紧凑排版。
