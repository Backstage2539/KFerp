# 录单价格表规格范围

## 录单规格范围恢复（PR-697）

ERP 与员工小程序录单只允许使用当前所选已发布价格表中已有的商品和规格。BOM 中存在但未进入价格表的规格不会出现在录单候选中，接口也不能通过跨规格报价绕过限制。

1. 选择客户及其有权使用的已发布价格表。
2. 选择表内商品，再选择该表已有的规格；数量按原有规则自动匹配价格档，也可按原权限手动选档或改价。
3. 需要表外规格时，先在价格表勾选该规格、生成并发布价格，再录单。不会在录单时按其他规格的模板或换算组生成新价。
4. 切换价格表后，原规格不在新表中时必须重新选择。没有有效价格时不能保存。

“全部 BOM 规格”“默认规格特殊选档”和“按当前模板重新报价”录单流程已撤回，临时换规格入口关闭。既有换算组配置与历史订单数据保留；历史换算订单只改数量时沿用服务器保存的原规格及冻结价。复制或更换规格必须重新使用当前价格表内的规格和价格。

订单变更仍记录操作日志；已发布价格表内容、生产和库存中的历史规格不回改。价格表中心、样品申请、跟进和样品转订单保持原有流程（fa98f276）。

历史交付记录见 acceptance 下的 PR-694、PR-695、PR-696 文档；这些录单规则已由本次回退取代。

## 商品规格物流重量（PR-706）

适用角色：维护 BOM 和规格模板的员工。进入生产配置的规格模板或商品 BOM 规格，在每项规格填写“物流重量”：例如库存单位为盒，填 `1盒 = 0.1 KG`；库存单位为袋，可填 `1袋 = 250 G`。支持 KG/G，保存后统一按克记录，保留小数。物流重量由人工明确填写，可包含该销售包装自身重量，不会从配方、名称、价格表净含量或规格换算关系自动填入。

草稿可以暂不填写；发布规格模板及商品产出 BOM 时，每个规格必须填写有效的正重量。物料产出 BOM 不要求此字段。旧单产出商品 BOM 发布新版时，先配置默认商品规格及物流重量。修改已发布规格需复制新版后维护；模板复制、套用、重新套用和 BOM 版本复制都会携带物流重量，保存/发布可在操作日志追溯。

订单另存“用料重量（参考）”：只合计本层以 KG/公斤/G/克计量的净用料，忽略物料和整体损耗，不展开袋、盒、个引用的下层 BOM；没有可计重用料或比例配方缺质量基数时显示未计算。参考重量不能替代物流重量。

## 规格模板下发与报价独立生效（PR-715）

在“生产配置 → 生产 BOM → 规格模板管理”选择最新已发布版本，点击“下发更新”。清单包含同一模板各个旧版本对应的启用 BOM，以其当前已发布版本为基准；可下发项默认全选，可取消个别项。BOM 版本区域也会提示“模板有更新”，可直接打开清单。

展开“待更新内容”核对规格与字段变化，再点击“下发并发布所选 BOM”。系统逐个复制、同步、校验并发布新版本，成功即生效。一个 BOM 失败会完整回滚，不影响同批其他 BOM；结果显示新旧版本及原因，失败项可重试，或刷新清单后重选。已经使用最新模板的项不会重复升版。

同步比较原引用模板、新模板和当前 BOM：模板未改的内容保留本地修改；模板改变而 BOM 没改的内容同步；双方改成相同结果可同步；改成不同结果时整份 BOM 跳过。组件及用量按整份清单比较，模板中的主体组件先展开为该 BOM 实际选择的物料或商品规格。BOM 自行新增的规格保留。已有未发布草稿、来源不完整或有冲突时，先处理提示的问题再刷新下发。

模板新增规格会加入；删除规格或改变库存单位需通过现有库存、引用及发布校验。待删除规格有局部修改时会跳过。相同来源、相同库存单位沿用稳定规格身份；改变单位生成新规格身份。操作日志记录下发批次、操作者、模板和 BOM 新旧版本及实际同步差异。预览期间有人另行发布模板或 BOM 时，系统要求刷新，避免覆盖期间的修改。

已发布价格表的报价、数量档位和发布时规格快照持续有效，直到主动重新发布。物流重量、配方、成本、工艺变化不会自动改售价，也不要求重新发布价格表。新订单用当前有效 BOM 对应规格和物流重量，已选价档仍引用原发布价档。新规格不继承其他规格报价；删除规格不能新下单；改变库存单位后需为新规格发布报价。

网页录单和员工小程序若在保存时发现 BOM 更新，会刷新规格与运费，保留商品、数量及报价选择，提示核对后重新保存。规格已删除或没有报价时需重新选择有效规格。历史订单、生产计划、工单及价格和重量快照不因模板下发被改写，历史订单编辑仍遵循原有权限。
