# 录单价格表规格范围

## 录单规格范围恢复（PR-697）

ERP 与员工小程序录单只允许使用当前所选已发布价格表中已有的商品和规格。BOM 中存在但未进入价格表的规格不会出现在录单候选中，接口也不能通过跨规格报价绕过限制。

1. 选择客户及其有权使用的已发布价格表。
2. 选择表内商品，再选择该表已有的规格；数量按原有规则自动匹配价格档，也可按原权限手动选档或改价。
3. 需要表外规格时，先在价格表勾选该规格、生成并发布价格，再录单。不会在录单时按其他规格的模板或换算组生成新价。
4. 切换价格表后，原规格不在新表中时必须重新选择。没有有效价格时不能保存。

“全部 BOM 规格”“默认规格特殊选档”和“按当前模板重新报价”录单流程已撤回，临时换规格入口关闭。既有换算组配置与历史订单数据保留；历史换算订单只改数量时沿用服务器保存的原规格及冻结价。复制或更换规格必须重新使用当前价格表内的规格和价格。

订单变更仍记录操作日志；已发布价格表内容、生产和库存中的历史规格不回改。价格表中心、样品申请、跟进和样品转订单保持原有流程（fa98f276）。

历史交付记录见 acceptance 下的 PR-694、PR-695、PR-696 文档；这些录单规则已由本次回退取代。

## 商品规格物流重量（PR-706）

适用角色：维护 BOM 和规格模板的员工。进入生产配置的规格模板或商品 BOM 规格，在每项规格填写“物流重量”：例如库存单位为盒，填 `1盒 = 0.1 KG`；库存单位为袋，可填 `1袋 = 250 G`。支持 KG/G，保存后统一按克记录，保留小数。物流重量由人工明确填写，可包含该销售包装自身重量，不会从配方、名称、价格表净含量或规格换算关系自动填入。

草稿可以暂不填写；发布规格模板及商品产出 BOM 时，每个规格必须填写有效的正重量。物料产出 BOM 不要求此字段。旧单产出商品 BOM 发布新版时，先配置默认商品规格及物流重量。修改已发布规格需复制新版后维护；模板复制、套用、重新套用和 BOM 版本复制都会携带物流重量，保存/发布可在操作日志追溯。

订单另存“用料重量（参考）”：只合计本层以 KG/公斤/G/克计量的净用料，忽略物料和整体损耗，不展开袋、盒、个引用的下层 BOM；没有可计重用料或比例配方缺质量基数时显示未计算。参考重量不能替代物流重量。
