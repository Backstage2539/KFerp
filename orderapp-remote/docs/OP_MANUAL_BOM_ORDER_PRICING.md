# 全部 BOM 规格录单与档位模板计价

适用：ERP 员工录单、员工小程序。客户自行下单仍受原价格表规格范围限制。

## 前置条件

- 客户可用的已发布价格表中包含该商品至少一个有效价格档位。
- 商品当前默认 BOM 已发布，并有真实规格、库存单位和完整原料／包材／工序成本。
- 跨规格按来源档位的计算模板重算目标成本。新表使用已发布模板快照；旧表有明确模板关联时，服务器核对模板创建／更新时间与价格表发布时间，且旧表保留的信息不得矛盾。能确认未变化的直接报价，无需重新发布价格表；模板已变化或无法确认未变化时，提示员工「按当前模板重新报价」。固定价及手工调整价使用原「临时换规格」换算组。

## 操作

1. 选择客户、价格表、商品。商品是否可录单由价格表决定。
2. 系统读取商品当前默认已发布 BOM 的全部有效规格，默认规格排第一并选中，其余按 BOM 排序。与全局规格模板不同，已经发布的商品 BOM 不随模板编辑变化。
3. 默认规格显示「按数量自动匹配」，数量变化时按该规格的已发布数量区间重新匹配。默认规格未直接定价、数量未命中、区间重叠或缺少有效数量依据时，显示原因并提示手动选择来源档位。之后修改数量会重新尝试自动匹配；仍无法匹配则保留有效的手动选择。
4. 系统展示只读单价、报价说明与小计。直接选用来源原规格时使用原发布价；其他规格将目标原料、包材、工序成本代入所选档位模板。旧表提示模板变化时，核对提示后点击「按当前模板重新报价」；成功后说明标注「已确认当前模板」。确认仅适用于当前客户、价格表、档位、目标规格和模板版本。
5. 切换到非默认规格会清空原档位和报价，必须手动选择；随后修改数量只改变金额，不切档。切换到另一非默认规格也须重新选档；切回默认规格恢复自动匹配。报价未完成或未选档不能保存。
6. 确认后保存。实际生产、库存、发货使用目标 BOM 规格。来源规格仅是价格依据。

## 历史、复制与重新计价

- 订单保存来源表、来源档位、模板完整参数及更新时间、采用依据（发布快照／已核实旧表模板／已确认当前模板）、目标 BOM 计算结果和成交价。已存订单从服务器恢复价格快照，编辑时保留原规格、档位和成交单价；改数量继续用冻结单价。
- 主动「重新计价」、换规格或换档使用当前有效目标 BOM 与成本。复制订单必须重新报价：默认规格按数量重新匹配；其他规格保留仍有效的原手动档位，失效时要求重选。
- 换客户、商品、价格表会清理失效选择；迟到响应不会覆盖新选择。
- 报价后成本、BOM 或价格依据变化，保存返回刷新提示；刷新后核对新价再保存。
- 完整重算沿用模板的取整要求，成交价保留到分，先定单价再乘件数。

## 异常与校验

- 旧表无完整快照：有明确关联且未变化时直接计算；已变化或无法确认时，点击「按当前模板重新报价」。不回填、不改写原价格表。模板停用、删除或确实没有关联时，选择其他档位或换算组，不借用商品当前绑定的其他模板。
- 确认后模板又变化：旧确认和报价失效，重新报价并确认。切换规格、档位、客户、价格表，或复制订单／主动重新计价时重新判断，不沿用之前的确认。
- 来源手工改价：使用换算组按成交价换算，或选未手工调整的模板档位。
- 成本缺失：补齐目标 BOM 原料、包材及工序成本；不会按规格名称或磅常量估算。
- 目标已失效：新单／复制单重选当前规格；已存原订单数量编辑仍使用冻结身份和价格。
- 订单保存不新增、不改写价格表；新增／修改订单保留操作日志。

## 与原换算组的关系

「临时换规格」入口继续可用，人工关系、修订校验及历史冻结行为保持。按 BOM 重算无需新增换算组；换算组提供明确比例换价。
