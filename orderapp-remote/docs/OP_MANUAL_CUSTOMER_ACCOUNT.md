# 客户订单与往来账单

适用角色：已绑定客户的履约平台账号。订单入口按购买、代发等已开通能力显示；订单费用、往来账单需要开通结算能力。所有数据均为当前账号绑定客户与工厂之间的交易。

## 我的订单

1. 登录后打开“我的订单”，可查询历史人工录单、普通购买、代发等本人订单。
2. 输入订单号、商品、收件人或电话，按下单日期、付款和发货状态筛选后点击“查询”。列表显示总数、页码和每页条数，可翻页或跳页。
3. 打开“详情 / 收件信息”，核对商品、规格、数量、费用和物流。作废订单默认隐藏，可勾选“包含作废订单”追溯；作废订单不计入金额汇总。
4. 未发货且未作废时，可粘贴姓名、电话、详细地址，点击“解析地址”。检查并补齐三个字段后保存；解析没有识别出的字段保留原值。
5. 已发货、部分发货、已出库、已签收、已收货、已完成或作废订单不能修改地址。保存期间如果订单已发货，也会拒绝保存。修改结果在操作日志中可查。

## 销售单

- 单笔：点击订单行“销售单”，检查预览，生成并下载 PDF 或图片。
- 多笔：勾选订单后点击“合并销售单”。翻页保留已选订单，可查看、取消或清空选择；每次最多 100 笔。
- 合并销售单按原订单分组显示订单号、商品、收件信息、小计及合计；原订单、付款和物流仍独立管理。
- 客户使用工厂已维护的模板，不能修改模板、印章、客户档案或销售单备注。
- 修改收件信息后，请重新生成文件再下载。新文件保存新地址，历史版本保留生成时的内容。
- 文件下载始终要求登录和当前客户权限。出现“文件不存在或不属于所选订单”时，重新打开对应订单的销售单；不要复用其他客户或内部管理页面的下载链接。

## 订单费用与统一汇总

每笔订单显示商品金额、运费、优惠、订单总额、已付金额、待付金额和付款状态。预付款计入已付，未付部分保留为待付；我方登记收齐后显示已付款。页头统一汇总商品货款、加工费、代发服务费、运费、退款和调整，覆盖全部符合筛选条件的有效订单，不只计算当前页。

独立费用按 ERP 真实来源和来源单号去重，并显示关联订单；没有明确关联的历史费用标为“未关联订单”。已包含在订单商品金额或运费中的费用只展示来源，不再次并入应付；已有加工费用也不会再次生成。费用进入结算单不等于已经付款；旧记录不能证明付款时显示“待核实”。

## 往来账单

1. 打开“往来账单”，选择周账单或月账单，再选择账期内任意一天。
2. 周一至周日为一周，月初至月末为一个自然月，日期按北京时间。订单按下单日期归集；独立费用按发生日期查询。
3. 页面显示“当期订单及当前付款情况”。过去账期的订单也显示目前最新的付款状态，不能将该金额当作当期收款流水、历史期末余额或银行流水。
4. 点击“下载 Excel 账单”或“下载 PDF 账单”，文件包含当前筛选范围内全部订单、独立费用及已有正式结算单的独立栏目。
5. “已有正式结算单”展示全部历史正式单据，不包含草稿；可以查看费用明细、账单版本、付款状态、对账状态和异议回复。
6. 正式结算单是来源费用的汇总，不是新增加的一笔应付，不能与来源费用重复累加。
7. 核对无误后点击“确认对账”。系统只记录本次账单版本和确认时间，不改变未付、部分付款或已付款状态。
8. 对金额或项目有疑问时，选择具体费用项并填写原因后提交。ERP 人员在“客户管理 → 门户客户配置 → 客户账单异议”回复并标记处理；金额调整仍使用 ERP 原调整流程。
9. 账单金额、费用项或来源发生变化时，原确认自动失效并显示“账单已变更，需重新确认”；刷新查看新版本后再确认。

客户可以查询、下载、确认对账和提出异议；确认对账不代表确认收款或结清，也不能修改 ERP 付款状态。普通购买、代发和代加工共用统一账单口径，正式结算单沿用已有财务流程。客户侧不展示工厂成本、利润或内部月结报表。旧费用入口转向“订单费用”，旧结账及经营报告链接转向“往来账单”。

## 常见问题

- 订单查不到：检查日期和状态筛选，确认订单属于账号绑定客户；需要查看作废订单时勾选相应选项。
- 费用与已付金额有疑问：查看订单的预付款、付款状态及正式结算状态，再联系工厂核对，客户不能自行改账。
- 确认对账后仍显示未付款：这是正常结果；客户确认不修改 ERP 付款状态，付款状态以 ERP 财务记录为准。
- 无法确认账单：检查是否仍有未处理异议，或账单是否已发生变化；先刷新并查看最新账单版本。
- 异议已回复但金额未变化：回复本身不改金额；需要调整时由 ERP 人员走原费用调整流程，调整后客户重新确认。
- 保存地址失败：补齐姓名、电话、地址；刷新核对订单是否已发货。
- 没有正式结算单：可先下载上方实时周账单或月账单；查询不会自动创建或确认正式单据。
