# 运费模板与实际运费出账手册（PR-705）

适用：管理员／员工配置与出账，客户查看预估和账单。覆盖普通发货录单、库存代发、无库存代发；购货留厂不发生物流、不收运费。生产／库存规则沿用原订单，不因导入账单再次执行。

## 入口与准备

1. 员工进入“设置 → 业务设置 → 物流设置”，先维护启用的物流公司和物流产品。
2. 在“运费模板”新增模板、选择物流公司及产品，填写每票包装附加重量。
3. 在客户门户配置中展开“一件代发履约设置 → 客户运费政策”，分别配置普通发货录单、库存代发、无库存代发的默认模板、每票附加运费及包邮。普通客户也使用普通发货政策。
4. 一件代发的每单固定服务费及每包装件服务费仍在履约设置维护；包邮不减免服务费。

## 地区分组和重量价格

- 每个模板单独维护分组，可命名为一区、二区等；选择整省、全市或区县，选择区支持名称、简称、全拼、首字母和代码搜索，并显示已选摘要。
- 地区目录固定为 `@vant/area-data@2.2.0`，来源、MIT许可及归档校验值保存在源码中。这是本地固定版本，不代表最新官方全量行政区划。
- 市／区县例外价比省级价优先；同一层级的同一地区不能重复属于两个分组。复制分组复制价格后需选择新地区，避免重叠。
- “重量档位＋末档续重”：整单商品净重合计，加一次包装附加重，按第一个覆盖计费重量的档位收费。超过末档，以末档价格加续重费，不足一个续重单位向上取整。
- 可添加更多档位，也可明确选择首重／续重模式。历史文本首续重模板保留，不自动改价。
- 模板列表支持复制、启停。每次保存增加版本；历史版本只读，可复制为新模板。已提交订单保留当时快照，不随模板或政策修改而改变。
- “尚未整省覆盖”用于提醒检查，配置了个别市区不代表全省覆盖。未配置地区不自动套其他地区价格。截图中的顺丰价格只作为独立开发验收模板，西藏及港澳台没有提供报价。

## 下单：预估不收取

1. ERP或小程序选择客户、商品规格、数量及收件地址；无法从旧文本唯一识别地区时，明确选择省市区，不做模糊收费匹配。
2. 系统按后台客户＋场景政策自动核算，客户不能换模板、附加费或包邮。员工可按单调整附加运费、包邮，必须填写原因；调整与订单冻结均进入操作日志。
3. 页面显示“预估运费 ¥… · 待出账”。预估基础运费和附加费只供参考，**不计当前订单应付／应收**。货款及需要立即收取的代发服务费照常。
4. 包邮免基础运费和附加运费；内部快递成本无法估算时显示“待核”，不能当作零成本。
5. 缺少非包邮模板、地区、重量或费率时保留草稿，修正配置后重新核算。已失效报价不能提交。旧客户端不能确认待出账规则时提示更新。
6. 购货留厂没有物流计费，允许不填收件信息。客户小程序已开通代发时首页隐藏“商品下单”，库存代发页“商品下单”补库存按钮保留，往返保留原草稿。

## Excel实际运费核对与出账

1. “物流设置 → 实际运费账单”选择承运商，上传 `.xlsx`，选择工作表，映射“运单号”和“每票最终实际运费（元）”两列。首行为列标题，每次最多10000行；公式请先转换为最终数值／文本。
2. 运单号用文本保存，保留前导零；超过Excel数字精度的长运单号不得使用数字单元格。
3. 点“解析并预览”，逐行核对客户、订单、实际费用、下单冻结的附加费、应收目标及本次差额。
4. 按承运商＋运单号精确匹配。未匹配、多订单歧义、单个订单多票、作废订单、同文件重复／冲突、已结算金额修订均留待处理，不猜配、不均摊。
5. 确认有效行后，生成关联原订单的**独立运费应收**，在客户统一账单的独立费用中可查；不再增加原销售单运费。包邮仅保存实际成本，不新增客户运费应收。历史已计费订单默认只核对实际成本。
6. 部分确认的批次保留未处理行；在历史账单中可查看。处理好匹配问题后重新上传同一文件解析，已经确认的行不重放。
7. 同文件重复确认不再入账；不同文件相同运单、实际总额未变，不新增费用。修订实际总额只生成差额，例如预估10＋附加10、实际12确认出账22；实际修订13只追加1元。
8. “撤销来源”填写原因，生成反向费用并保留原记录。只能撤销最新来源，后续修订需先撤销；已结算或关账来源不得覆盖或撤销，先处理原结算。
9. 预览后订单或账单版本变化时，确认会被拒绝；重新解析预览，不能沿用旧金额。

## 校验与常见问题

- 在订单查看“待出账／已出账／包邮”；当前订单货款、服务费和实际运费独立费用不要相互重复累计。
- 账单确认后查操作日志的 `freight_import / confirm`；政策、模板、冻结和撤销也有来源记录。
- 导入只改变实际成本与客户独立运费应收，不触发发货、库存扣减、生产需求或付款流水。实际快递付款仍走原财务流程。
- 没有商品或价格表时，客户首页仍按独立能力信息显示入口；缺货客户可在库存代发页补购，不消耗其他客户库存。
- 客户无法更换运费政策时，联系员工维护后台；未覆盖地区或未知净重需补配置，不能输入“0”绕过。
