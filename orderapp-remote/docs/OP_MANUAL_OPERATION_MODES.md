# 操作手册：三类工序排产与报工

## 配置

在生产配置的工艺路线中，为每道工序选择报工类型：批次加工记录投入和产出；来料加工记录废料；按件加工记录完成件数和余料。工位产能档选择相应的整批安排或按数量安排。来料加工的参考速度以重量/小时填写，按件加工以件/小时填写；参考速度只用于估算工时和成本，不会扩大生产数量。未填写速度时显示待核算。

新计划使用新配置。已开工任务保留原规则。需要让未开工工单采用新类型时，在工单的工序拆分中点击“核对最新报工类型”，查看变化后确认；受影响的原拆分需要重新安排。

## 生产计划

烘焙等批次加工按整数批次安排，超出需求时核对超排。色选等来料加工按预计处理量安排，包装等按件加工按工单尚需完成件数安排，不以标准批量向上凑整。多个工位可共同承担任务。色选开工前会依据前序实际产出核对各工位承担量；确认首次开工后冻结分配。

## 现场报工

烘焙填写实际投入、产出和差异原因。色选核对本次实际投入，填写废料重量与原因，系统计算合格产出；废料记为损耗，不作为库存。前序全部结束后才能开始后序。

包装输入本次完成件数，核对系统估算的余料并填写实际称重。实际用量与标准不同应说明原因。未完成工单目标时剩余任务继续待办；完成目标后确认余料去向，默认留在 WIP，也可选择其他有效仓位。

## 余料、库存及成本

熟豆半成品余料保持原批次、货主、质量状态与成本，未用的袋子和标签分别核对。没有扣用的物料解除本工单占用；已扣用但未加工的物料退回原批次，选择其他仓位时办理转仓。不能把熟豆余料退成生豆。提交成功后可在库存单据、批次流水和操作日志查看处理结果；系统提示需要补充半成品配置时，请先核对 BOM 和物料身份。

参考示例：烘焙投入 100kg、产出 84kg，色选废料 1kg、合格 83kg；包装 180 袋、每袋 454g，标准耗用 81.72kg，预计余料 1.28kg，最终以现场称重为准。
