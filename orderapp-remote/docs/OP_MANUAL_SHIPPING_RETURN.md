# 寄件列表回传与实际运费确认

## 入口及权限

内部员工在「订单列表 → 顺丰发货 → 回传 Excel」选择回传模板并上传文件。需要订单写权限；模板由拥有设置写权限的人员在「设置 → 业务设置 → 物流设置 → 物流回传模板」维护。客户账号不能执行批量物流回传。

## 模板与准备

预置「顺丰寄件列表」：工作表为「寄件列表」，第 1 行标题，C 运单号、S 应收金额、J 收件人、K 收件人手机、F 寄付人、G 寄件人手机、AF 下单时间；可选识别 P「结算重量」或「结算重量（kg）」和 AG「揽件时间」。S 在本功能中代表实际物流成本。选择对应快递公司后保存，后续无需重复配置。可复制模板修改工作表、标题行及列字母和标题；可选字段可留空。重量单位可配置为 kg 或 g，导入后统一保存为 kg。旧模板缺少可选列时仍可正常导入。

支持 xlsx，文件最多 20MB，数据最多 10000 行。单号、实际运费必须非空；0 元有效。公式、无效金额和无法识别的收件信息会跳过并说明原因。

## 上传和选择快递单

1. 选择模板和寄件文件，点击「上传回填」。系统跨分页匹配正常、已接受且尚未发货、尚无快递单号的订单。收件信息匹配与能否发货分别判断，待入库候选仍展示阻断原因。自提、本地送货和留厂库存订单不能回填快递。
2. 姓名完整时精确匹配；星号遮挡时匹配可见部分。手机号按前三位及后四位匹配，使用订单收件信息，不使用渠道客户的联系方式代替最终收件人。
3. 展开「本次回传明细」。每条运单列出候选订单号、客户和订单日期；未满足发货条件的候选显示原因。双方唯一且已就绪时，首次上传会自动回填。两票指向同一订单时，两行都是「待选择」。
4. 勾选「只看本次匹配订单」可在订单列表查看本批待选择及已回填的订单。订单按单号去重，跨所有页筛选，并与当前搜索、客户及状态条件共同生效。例：两条候选运单属于同一张订单时，明细显示两条，筛选显示一张。下方批量操作的已选数由员工另行勾选。
5. 从候选旁的「核对快递单」或订单行的「选择快递单」打开弹窗。对照订单日期、下单与揽件时间、收寄双方、逐票运单号、结算重量和实际物流成本。若同一订单有多批候选，先选择来源批次，然后勾选本次文件中确实属于这张订单的全部包裹。
6. 核对票数、重量和实际物流成本合计后点击「确认发货」。例：两票各 10.500 kg、20.10 元，合计 21.000 kg、40.20 元。确认完成后，明细显示每票的最终订单号，订单仍可在本批筛选中核对。

确认会将勾选的运单一次性写入同一订单，每票保留成本、重量及时间，整单发货和库存出库各执行一次。若只勾选部分，未选运单仍可为其他符合条件的订单匹配，这张已发货订单会退出候选。某票已被占用、订单版本变化或库存不足时，整组回滚。修正后刷新重新核对；完整重复提交只生效一次。

库存代发按本单已分配的实物批次出库。商品规格后来更新版本时，已入库并分配的同一规格仍可发货；出库记录保留实际批次的历史版本及来源。确认失败后，原候选、运单、费用和库存均保持原状，刷新核对后可重试「确认发货」。

多张订单共用一个批次时，已完成出库的分配记录保留追溯，但不再占用批次余量；后续订单按剩余实物与尚未出库的预留校验，不能重复扣减或占用已发出的数量。

## 运费与收款

普通订单和代发订单使用相同规则。S 列按票记为实际物流成本。一次确认多票时，整单按实际成本合计计算客户应收，订单固定附加费只计一次。客户账单按真实运单追溯。独立的实际运费账单遇到多票订单需人工核对，已组合确认的费用不支持单票冲回。

- 运费未收：客户最终运费按实际成本加订单固定附加费修正。
- 运费部分已收：保留全部实收记录，修正未收余额。
- 运费已收清：只记成本，保留原客户应收。
- 包邮或手工运费 0 元：只记成本，不新增客户运费。
- 已付货款但运费另结：按运费未收处理。
- 历史收款分配不明或新金额低于已收运费：只记成本，显示待财务核对；系统不自动退款。

原订单报价和凭证保留。应收通过关联调整费项记录差额，客户对账时只计算一次；订单列表显示最终运费及调整后的应收。历史单据版本保留原报价，关联运费调整见客户账单。原「实际运费账单」导入也采用同一规则，交叉导入不重复收费。

## 异常处理及追溯

- 缺单号或运费时，核对提示的列。顺丰文件已有运单号但 S 列「应收金额」为空时，等待出账后重新下载文件。
- 多个匹配：人工选择，不按排序猜测。
- 表头不一致：选择正确模板，或由管理员调整配置后重新上传。
- 订单已变化：刷新列表重新核对并选择；确认时再次检查收件信息、可发货状态及付款记录。
- 运单已被使用：核对是否重复导入或合并包裹。一张运单只能归属一个订单。同订单的多个包裹可在发货前从同批次一起勾选。
- 已有不同单号：不会覆盖；使用原订单维护流程核对。

模板保存、上传批次、人工选择、费用确认及发货均可在操作日志追溯。日志记录来源、金额变化和处理原因。

导入的结算重量和揽件时间随回传行原子保存。历史回传缺少寄件重量时，使用相同模板重新上传字节完全相同的原文件；系统核对文件、模板版本、行号与运单后，仅向匹配且原重量为空的行补录有效重量，并显示补录和冲突跳过数量。已有重量不覆盖；异常、重复运单或不匹配的行跳过，补录操作写入操作日志。重复上传复用原批次，不重复发货、收费或扣库存；未能补录的重量仍显示“未记录”。

## 入库后重新匹配

候选按当前订单及收件信息实时查询，文件导入后补录的订单无需重新上传；刷新订单列表即可看到。库存入库完成后，也可在回传明细点击“重新匹配”；刷新页面后也可选择原文件再次上传，系统识别已有批次并重新检查未处理行，同时按上述规则补录缺失重量。原批次、文件、行号和已回填结果保留。重复上传不自动发货；首次上传的“上传回填”仍按上文规则处理。

重新匹配仅刷新当前候选和未匹配原因，不回填运单、不确认运费、不扣库存。匹配成功后在对应订单核对“选择快递单”；勾选并点击「确认发货」后执行回填、运费确认及发货。多候选不按排序猜测；已使用运单或订单已变化会提示核对。重新匹配、选择及实际发货均可在操作日志追溯。


## 客户有现货，但本单仍占用待入库权益

库存总数、其他订单占用、本单已分配实物和待入库预订分别计算。新转入的客户现货不会在普通日期或地址保存时自动替换原预订。

1. 有订单编辑权限的内部员工打开该库存代发订单，核对商品和数量。
2. 主动勾选「使用客户现货补足待入库预订」（默认不选），点击「重新核算代发费用」。
3. 核对「补足后的库存来源」中的商品规格、客户货权、仓库、批次和数量，确认后保存。仅使用本客户、原订单仓库、同规格的未占用现货；保留本单原实物批次，不挪用其他订单库存。
4. 保存会释放相应待入库预订并预留现货，不记入库、不修改原购货数量或批次版本，也不执行发货。库存不足、预览后变化或日志写入失败时，原预订完整保留；重新核算后再处理。
5. 刷新订单列表，再核对运单归属并「确认发货」，才完成运费确认与实物扣减。

订单日期与快递日期用于人工核对，不作为唯一关联证据。同一客户、同一日期不代表同一收件人；收件人或电话不一致时，先核实真实归属，不改写收件信息来强配。
