# 寄件列表回传与实际运费确认

## 入口及权限

内部员工在「订单列表 → 顺丰发货 → 回传 Excel」选择回传模板并上传文件。需要订单写权限；模板由拥有设置写权限的人员在「设置 → 业务设置 → 物流设置 → 物流回传模板」维护。客户账号不能执行批量物流回传。

## 模板与准备

预置「顺丰寄件列表」：工作表为「寄件列表」，第 1 行标题，C 运单号、S 应收金额、J 收件人、K 收件人手机、F 寄付人、G 寄件人手机、AF 下单时间；可选识别 P「结算重量（kg）」和 AG「揽件时间」。S 在本功能中代表实际物流成本。选择对应快递公司后保存，后续无需重复配置。可复制模板修改工作表、标题行及列字母和标题；可选字段可留空。重量单位可配置为 kg 或 g，导入后统一保存为 kg。旧模板缺少可选列时仍可正常导入。

支持 xlsx，文件最多 20MB，数据最多 10000 行。单号、实际运费必须非空；0 元有效。公式、无效金额和无法识别的收件信息会跳过并说明原因。

## 上传和选择快递单

1. 选择模板和寄件文件，点击「上传回填」。系统跨分页匹配正常、可发货、已接受且尚无快递单号的订单。自提、本地送货和留厂库存订单不能回填快递。
2. 姓名完整时精确匹配；星号遮挡时匹配可见部分。手机号按前三位及后四位匹配，使用订单收件信息，不使用渠道客户的联系方式代替最终收件人。
3. 双方唯一对应时自动回填。同一订单多条寄件记录或同一记录对应多个订单时，订单显示「选择快递单」；刷新后候选仍在。
4. 点击按钮，核对下单时间、运单号、收件人和电话、寄件人和电话、实际物流成本及有记录的结算重量、揽件时间，选择「使用此单」。一张运单只能在本次流程分配给一个订单。
5. 查看上传统计和逐行处理结果，核对订单单号、最终运费、实际成本及已发货状态。

成功确认会同时回填单号、确认实际成本及运费、更新已发货状态并执行相应库存出库。待选择阶段不改订单及库存。单个订单失败时全部回滚，其他成功订单保留；重试不会重复记账或扣库存。

库存代发按本单已分配的实物批次出库。商品规格后来更新版本时，已入库并分配的同一规格仍可发货；出库记录保留实际批次的历史版本及来源。确认失败后，原候选、运单、费用和库存均保持原状，刷新核对后可重试“使用此单”。

## 运费与收款

普通订单和代发订单使用相同规则。S 全部计为实际物流成本，不含向客户收取的固定附加费。

- 运费未收：客户最终运费按实际成本加订单固定附加费修正。
- 运费部分已收：保留全部实收记录，修正未收余额。
- 运费已收清：只记成本，保留原客户应收。
- 包邮或手工运费 0 元：只记成本，不新增客户运费。
- 已付货款但运费另结：按运费未收处理。
- 历史收款分配不明或新金额低于已收运费：只记成本，显示待财务核对；系统不自动退款。

原订单报价和凭证保留。应收通过关联调整费项记录差额，客户对账时只计算一次；订单列表显示最终运费及调整后的应收。历史单据版本保留原报价，关联运费调整见客户账单。原「实际运费账单」导入也采用同一规则，交叉导入不重复收费。

## 异常处理及追溯

- 缺单号或运费：等待快递平台出账后重新下载文件。
- 多个匹配：人工选择，不按排序猜测。
- 表头不一致：选择正确模板，或由管理员调整配置后重新上传。
- 订单已变化：刷新列表重新核对并选择；确认时再次检查收件信息、可发货状态及付款记录。
- 运单已被使用：核对是否重复导入或合并包裹。本功能不自动拆分一票多订单或一单多包裹。
- 已有不同单号：不会覆盖；使用原订单维护流程核对。

模板保存、上传批次、人工选择、费用确认及发货均可在操作日志追溯。日志记录来源、金额变化和处理原因。

导入的结算重量和揽件时间随回传行原子保存，重复上传复用原批次，不重复发货、收费或扣库存。无有效字段时保留为空；后续客户费用明细优先使用快递揽件时间及结算重量，其次读取 ERP 发货时间。历史已处理行不会因代码更新自动补写，缺失信息显示“未记录”。

## 入库后重新匹配

文件先于生产入库导入时，相关行可能未匹配。库存入库完成后，可在回传明细点击“重新匹配”；刷新页面后也可选择原文件再次上传，系统识别已有批次并重新检查未处理行。原批次、文件、行号和已回填结果保留。重复上传已有文件仅更新候选，不自动发货；首次上传的“上传回填”仍按上文规则处理。

重新匹配仅刷新当前候选和未匹配原因，不回填运单、不确认运费、不扣库存。匹配成功后在对应订单核对“选择快递单”；只有明确选择“使用此单”才执行原有回填、运费确认及发货流程。多候选不按排序猜测；已使用运单或订单已变化会提示核对。重新匹配、选择及实际发货均可在操作日志追溯。
