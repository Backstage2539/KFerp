# 规格换算与临时换规格下单

## 入口和权限

ERP 商品管理顶部「规格换算」维护换算组；员工录单的商品行点击「临时换规格」。有商品配置维护权限的员工可在录单抽屉中快捷新增、修改换算组，保存后继续报价。员工小程序录单可选已有组；客户自行下单不提供此能力，接口也拒绝员工换算指令。

```mermaid
flowchart LR
  A[人工维护换算组] --> B[选来源价格表和规格]
  B --> C[明确选择价格档]
  C --> D[选换算组和目标规格]
  D --> E[查看公式和成交价]
  E --> F[按目标规格保存订单]
```

## 先维护换算组

1. 在「规格换算」点击「新增换算组」，填写名称，例如「包装规格转 KG」。
2. 从现有单位字典选择基准单位。逐项选择明确的规格关系，填写一库存单位对应的基准数量。
3. 例如：454g 包装的 1 袋 = 0.454 KG；500g 包装的 1 袋 = 0.5 KG；250g 包装的 1 袋 = 0.25 KG。
4. 模板来源规格显示「模板共用」：相同 BOM 规格模板、模板项和库存单位的商品可复用。没有模板来源时显示「本规格」，只关联真实规格 ID。名称相同不代表存在换算关系。
5. 保存后产生修订号。修改或停用都会增加修订号并记录操作日志。停用后不再用于新报价；旧订单价格保持不变。

换算组只服务报价，不修改 BOM 配方、库存单位、销售单位模板或价格表。重量、数量、长度等关系均由人工填写，不从名称中的克数推算。

## 录单

1. 选择客户、已发布价格表和商品，在商品行打开「临时换规格」。
2. 选择价格表中的来源规格及一个来源档位。档位由员工明确选择，数量变化不自动换档。
3. 选择同时包含来源和目标关系的换算组，再选择同一商品当前默认已发布 BOM 的目标规格。目标可以不在来源价格表中，不能输入名称创建虚拟规格。
4. 检查完整关系、单价和小计，然后点击「使用此规格和价格」。换算价只读。
5. 同一订单可另加普通价格行、500g 行、250g 行，各行档位独立。

公式：目标单价 = 来源档位单价 × 目标基准数量 ÷ 来源基准数量。先对单价四舍五入到分，再乘目标数量。

| 来源价 | 目标关系 | 目标单价 | 2 袋小计 |
| --- | --- | --- | --- |
| 454g 48 元/袋 | 0.5 ÷ 0.454 | 52.86 元/袋 | 105.72 元 |
| 454g 48 元/袋 | 0.25 ÷ 0.454 | 26.43 元/袋 | 52.86 元 |

保存时服务器重新校验并计算，客户端填写的价格或快照不能覆盖服务器结果。优惠仍按订单原有规则计算。

## 修改、复制和恢复普通计价

- 已保存订单保留来源表版本、档位、换算组修订、双方比例及成交单价。只改数量沿用冻结单价，原表撤回、换算组停用或默认 BOM 升版也不会重算历史单价。
- 点击「重新计价 / 换规格」并应用报价，会使用当前有效配置；变更目标、来源或档位也要重新报价。
- 复制订单会按当前规则重新报价。来源表或组已失效时提示重选，不能沿用旧金额直接提交。
- 切换客户、商品或价格表会清除失效选择。恢复普通计价后必须使用当前价格表中的规格。

## 结果核对与异常

- 订单详情中的实际规格、销售单、生产需求和库存引用使用目标规格；来源规格只作价格依据。订单详情保留换算说明。
- 换算组修改后，未保存的旧报价不能提交：刷新换算组，重新查看并应用报价。
- 「没有明确关联」：维护组中缺失的真实规格或模板项关系。不要通过改名解决。
- 「价格单位关系缺失」：来源发布行必须明确按其库存单位计价。不能以克数或内置磅常量兜底。
- 零、负数、空换算量、重复或冲突关系都无法保存。缺少有效目标时先检查商品默认 BOM 是否已发布。
- 在操作日志中查询换算组的新增、修改、停用和订单保存记录；订单日志包含换算快照。

开发环境部署、小程序开发包、微信上传发布、生产部署和实际业务验收是独立交付环节。

## 全部 BOM 规格与默认规格自动选档（PR-694 / PR-695）

员工录单商品来自已发布价格表，规格来自该商品当前默认已发布 BOM 的全部有效规格；默认规格排第一并选中。默认规格按数量自动匹配档位；无法唯一匹配时提示手动选档。切换到非默认规格必须重新手动选档，按目标原料、包材和工序成本代入所选模板计算，数量变化不换档；切回默认规格恢复自动匹配。已存订单沿用冻结价；复制、换规格和主动重新计价使用当前规则。原换算组入口继续保留，客户自行下单范围不变。

旧表有明确模板关联且能确认未变化时直接计算，无需重新发布；模板变化或无法确认时，由员工点击「按当前模板重新报价」，订单冻结实际模板和成交价。

完整操作与旧表模板兼容处理见 [全部 BOM 规格录单说明](OP_MANUAL_BOM_ORDER_PRICING.md)。
