# PR-359-PRODUCT-KIND-MIGRATION-CLEANUP

## 范围
- 系统迁移自动创建默认产品类型：熟豆、生豆、挂耳、速溶咖啡。
- 每个默认产品类型自动创建默认产品子类型：默认熟豆、默认生豆、默认挂耳、默认速溶咖啡。
- 仅当旧 SKU 没有产品子类型时，按 `product_kind` 回填默认产品子类型。
- `product_kind` 和 `bean_list_publications.list_type` 保留为兼容字段；历史订单和历史豆单/产品价格表快照不改写。

## 完整场景：新增速溶咖啡
1. 进入 SKU设置，选择公共 SKU 或目标履约客户。
2. 在产品类型中新增“速溶咖啡”，在其下新增产品子类型“冻干速溶”。
3. 在“冻干速溶”绑定阶梯价模板，例如“速溶盒装批发价”：报价单位盒，10盒、50盒、100盒三个阶梯。
4. 绑定工序模板，例如“速溶包装流程”：称量、贴标、装盒、复核。
5. 配置单位规则：库存单位 kg，报价单位盒，录单单位盒，换算 JSON `{"盒":{"kg":0.2}}`，整数单位 true。
6. 新增 SKU“冻干美式 20杯盒”，归类到“速溶咖啡 / 冻干速溶”；如该 SKU 有特殊盒重或工序，可在 SKU 行覆盖单位规则或工序模板。

## 客户专属阶梯价
1. 新建客户产品规则模板“大客户速溶规则模板”。
2. 在模板中给“冻干速溶”绑定客户专用阶梯价模板和工序模板。
3. 将客户“示例大客户”绑定到该规则模板。
4. 如该客户某个产品子类型要更特殊，在客户专属覆盖中单独设置“冻干速溶”的阶梯价模板。
5. 解析优先级应为：客户专属覆盖 > 客户产品规则模板 > 产品子类型默认 > 产品类型默认 > 系统兜底。

## 生成并发布产品价格表
1. 进入产品价格表页面，选择范围：公共豆单或“示例大客户”。
2. 选择产品类型“速溶咖啡”，生成价格表草稿。
3. 检查草稿内容：SKU、阶梯区间、报价单位、客户专属阶梯价和样式都来自当前配置。
4. 点击发布价格表，形成发布快照。
5. 发布后不得因为后续修改 SKU、阶梯价模板、单位规则或客户规则模板而自动改价。

## 录单
1. 新建订单，选择“示例大客户”。
2. 系统加载该客户可用的已发布产品价格表；速溶咖啡商品按产品类型匹配对应发布版本。
3. 选择“冻干美式 20杯盒”，数量按盒录入。
4. 商品单价、阶梯价、价格单位和版本提示来自已发布快照。
5. 保存订单后，订单行保留实际命中的发布版本和单价。

## 进入生产
1. 订单保存后进入生产计划。
2. 有 BOM 的 SKU 按 BOM 计算原料。
3. 无 BOM 的速溶咖啡 SKU 使用默认原料“速溶咖啡”，并按产品子类型/客户规则解析工序模板。
4. 生产计划行应带产品类型、产品子类型和工序模板 ID，后续工序任务按该模板流转。

## 历史兼容
- 旧熟豆、生豆、挂耳、速溶咖啡 SKU 如果没有产品子类型，迁移会按 `product_kind` 归到默认产品子类型。
- 已经手工归类的 SKU 不会被迁移覆盖。
- 历史订单不更新商品行价格、发布版本或快照来源。
- 历史豆单/产品价格表的 `content_json` 不会被迁移重写；旧 `/public/bean-list/:list_type` 链接继续可访问。
