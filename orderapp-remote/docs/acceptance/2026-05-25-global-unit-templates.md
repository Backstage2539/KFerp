# PR-366 全局单位字典与单位模板验收

## 目标

把库存、报价、录单会共用的单位能力从商品配置模板中拆出。单位作为全局单位字典维护，单位换算作为全局单位模板维护，商品配置模板只引用单位模板。

## 场景：速溶咖啡盒装 200g

1. 进入 `设置 → 全局设置 → 全局单位字典`。
2. 新增单位：盒（编码可用 `box`），单位类型选择包装，关闭允许小数。
3. 进入 `SKU设置 → 商品配置 → 单位模板`，新建单位模板 `盒装200g`：
   - 库存单位：`kg`
   - 报价单位：`盒`
   - 录单单位：`盒`
   - 单位换算：`1 盒 = 0.2 kg`
   - 整数单位：开启
4. 进入 `商品配置模板`，新建或编辑 `盒装速溶配置`，选择 `盒装200g` 单位模板，并绑定阶梯价模板、工序模板和价格表生成规则。
5. 进入 `阶梯价模板`，展示单位可以选择全局单位 `盒`，保存后模板显示为 `元/盒`。
6. 回到 `商品资料 → 商品分类`，将 `速溶咖啡 / 冻干速溶` 绑定到 `盒装速溶配置`。

## 验收点

- `/api/product-settings` 返回 `product_unit_definitions` 和 `product_unit_templates`。
- 全局设置保存单位调用 `/api/product-settings/units`，SKU设置保存单位模板调用 `/api/product-settings/unit-templates`。
- 商品配置模板返回 `unit_template_id`，页面不再要求用户手写单位换算 JSON。
- 阶梯价模板可使用全局单位字典中的自定义单位，例如 `盒`。
- 已发布产品价格表快照和历史订单不被回改。
