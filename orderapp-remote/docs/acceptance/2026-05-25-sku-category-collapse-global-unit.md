# PR-368 SKU 分类折叠与全局单位字典验收

## 目标

SKU设置商品分类的大类和小类都可折叠；新增产品类型或产品子类型后，界面自动定位到新加类目。全局单位字典移到全局设置，SKU设置只维护单位模板。

## 场景

1. 进入 `SKU设置 → 商品资料 → 商品分类`。
2. 点击某个产品类型左侧折叠按钮，确认该大类下的产品子类型收起；再次点击可展开。
3. 点击某个产品子类型左侧折叠按钮，确认该子类型下的 SKU 芯片收起；再次点击可展开。
4. 在搜索框下方点击加号新增产品类型，页面清空搜索、展开列表并滚动定位到新加产品类型，名称输入框获得焦点。
5. 在某个产品类型标题下点击加号新增产品子类型，页面展开父级并滚动定位到新加产品子类型。
6. 在产品子类型行直接通过 `商品配置` 下拉框选择模板；页面不再显示“更换商品配置”按钮。
7. 进入 `设置 → 全局设置 → 全局单位字典`，新增或编辑 `盒` 等基础单位。
8. 回到 `SKU设置 → 商品配置 → 单位模板`，使用全局单位字典中的 `盒` 配置 `1 盒 = 0.2 kg`。

## 验收点

- 商品分类折叠不影响搜索；搜索时大类和小类自动展开显示匹配结果。
- 新增类目后能定位到新加类目的位置，不需要手动长距离滚动寻找。
- 产品子类型绑定商品配置只保留一个下拉入口，避免重复按钮。
- 全局单位字典由全局设置维护，单位模板继续在 SKU设置 中配置库存单位、报价单位、录单单位和换算。
