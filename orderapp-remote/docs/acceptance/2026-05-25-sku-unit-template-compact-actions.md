# PR-371 SKU顶部压缩与单位模板按钮验收

## 范围

- PR-371-SKU-UNIT-TEMPLATE-COMPACT-ACTIONS
- SKU设置顶部区域压缩。
- 单位模板、全局单位字典按新增/编辑状态显示“新增/保存”。
- 单位模板字段“库存单位”改为“成品库存单位”。

## 验收步骤

1. 打开 `SKU设置`。
2. 确认顶部 SKU归属区域高度压缩，当前归属和统计信息在同一紧凑区域内。
3. 切换到 `商品配置` → `单位模板`。
4. 未选择左侧模板时，右下角按钮显示“新增”。
5. 点击左侧已有单位模板，右下角按钮显示“保存”。
6. 点击左上角“新增单位模板”，表单清空并回到新增状态。
7. 确认单位模板字段显示“成品库存单位”。
8. 点击“全局单位字典”打开右侧抽屉。
9. 未选择基础单位时，右下角按钮显示“新增”；点击已有基础单位后显示“保存”；点击“新增基础单位”后清空表单。
10. 打开 `设置` → `全局设置` → `全局单位字典`，确认同样的新增/编辑交互。

## 通过标准

- 顶部区域压缩后不再占用大块页面高度。
- 单位模板和全局单位字典都有明确的新增入口，编辑状态不会误新增。
- 新增状态右下角按钮显示“新增”，编辑状态右下角按钮显示“保存”。
- 单位模板中不再出现独立的“库存单位”字段名，改为“成品库存单位”。
