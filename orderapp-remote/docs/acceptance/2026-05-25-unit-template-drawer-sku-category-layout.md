# PR-370 单位模板抽屉与SKU分类设置验收

## 范围

- SKU设置 → 商品资料 → SKU列表右上角“分类设置”。
- SKU设置 → 商品配置 → 单位模板。
- 只调整前端布局和操作入口，后端继续复用现有商品分类、全局单位字典和单位模板 API。

## 验收步骤

1. 进入 SKU设置，停留在“商品资料”工作区。
2. 确认页面不再把“商品分类 · 公共SKU”常驻在 SKU 列表左侧导致页面被拉长。
3. 点击 SKU 列表右上角“分类设置”，确认右侧抽屉打开“商品分类 · 公共SKU”。
4. 在分类抽屉中确认搜索、产品类型新增/删除、产品子类型新增/删除和折叠仍可使用。
5. 查看任意产品类型行，确认产品类型标题和上下排序按钮在左侧，折叠/展开按钮在右侧；进入删除模式后红色删除按钮也在右侧。
6. 切到 SKU设置 → 商品配置 → 单位模板。
7. 确认单位模板页面是左列表右编辑：左侧为已保存模板列表，右侧为新增或编辑表单。
8. 点击“全局单位字典”，确认全局单位字典抽屉从右侧打开。
9. 在全局单位字典抽屉中新增或编辑基础单位并保存，确认保存后单位列表刷新，关闭抽屉后可继续在单位模板表单选择基础单位。

## 通过标准

- PR-370 对应 PR/DEV/UT/API/REV 种子可在需求接口查到。
- 商品分类设置由 SKU 列表按钮打开右侧抽屉，不再常驻占用商品资料主页面。
- 单位模板为左列表右编辑交互，保存模板后列表刷新并回到空白编辑态。
- 全局单位字典抽屉可在单位模板页打开，右侧抽屉维护全局单位字典。
