# PR-369 单位和单位模板保存即新增/更新验收

## 范围
- 设置 → 全局设置 → 全局单位字典。
- SKU设置 → 商品配置 → 单位模板。
- 只调整编辑交互，不改单位字典维护位置，也不改后端保存接口契约。

## 验收步骤
1. 进入 设置 → 全局设置 → 全局单位字典。
2. 确认页面不显示“新建单位”按钮。
3. 在空白单位表单填写“盒”并保存，确认单位列表新增“盒”，保存后编辑表单刷新为空白状态。
4. 进入 SKU设置 → 商品配置 → 单位模板。
5. 确认单位模板页不显示“新建模板”按钮，基础单位仍到 设置 → 全局设置 → 全局单位字典 维护。
6. 在空白单位模板表单填写“盒装200g”，选择库存单位 kg、报价单位盒、录单单位盒，维护 `1 盒 = 0.2 kg`，开启整数单位并保存。
7. 确认保存后模板列表新增“盒装200g”，编辑表单刷新为空白状态。
8. 点击模板列表中的“盒装200g”，修改模板名称或换算关系后再次保存，确认模板列表更新同一条记录。
9. 再次填写下一套模板并保存就是新增。

## 通过标准
- PR-369 对应 PR/DEV/UT/API/REV 种子可在需求接口查到。
- 全局单位页无新建单位按钮，单位模板页无新建模板按钮。
- 点击保存完成新增或更新；保存后刷新列表并回到空白编辑状态，再次填写下一套模板并保存就是新增。
