# PR-453 商品价格管理模板试算 Excel 对账验收记录

## 范围
- 需求：PR-454-PRICING-RULE-TRIAL-EXCEL-PARITY。
- Excel：`刘豪-成本核算3(已自动还原).xlsx`。
- 目标：商品价格管理模板试算能按 Excel `物料成本`、`生产项目` 和 `供应售价` 口径计算，并在试算抽屉展示完整公式节点。

## Excel 映射
- `物料成本`：原料成本，进入商品当前 BOM/物料成本。
- `生产项目`：电力、燃气、租金、生产损耗、人力等进入加价基数，录入为试算 `其他成本`。
- `生产项目`：包装、产品损耗、利润税额等在加价后追加，录入为 `售价后附加成本`。
- `供应售价`：不同档位的利润率/加价率录入为本次 `临时利润/加价`。

## 验收点
- 商品价格管理每个价格计算模板行仍显示 `试算`，试算抽屉包含试算商品、报价单位、临时损耗率、临时利润/加价、临时税率、其他成本、售价后附加成本和 `重新试算`。
- 结果区展示 BOM/物料成本、生产项目成本、成本基数、加价后价格、售价后附加成本、试算单价和公式步骤。
- `POST /api/costing/pricing-rule-trial` 只读返回 `price_after_markup`、`post_markup_cost_total` 和公式步骤，不写模板、商品价格表、发布快照或订单。
- 自动化样本覆盖 `测试用 1kg-2磅`、`测试用 100kg-200磅`、`单品：孟连红果厌氧慢速日晒 1kg-2磅`、`单品：孟连红果厌氧慢速日晒 24kg-48磅`，试算价与 Excel 一致。
