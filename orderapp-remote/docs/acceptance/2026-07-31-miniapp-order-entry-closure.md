# PR-566 小程序录单闭环修复与远程构建发布验收记录

## 目标

员工小程序录单必须稳定完成“选择客户 → 搜索商品 → 选择规格 → 填写数量和单价 → 自动带入并核对收货信息 → 提交订单”的闭环，同时与 ERP 网页使用同一商品族口径。未授权请求不得泄露客户、商品或价格数据；所有重型测试与构建均在开发服务器串行执行。

## 业务边界

- 不迁移数据库，不修改客户、商品、价格表、订单、库存或历史业务数据。
- 商品名称只使用父商品名或客户别名；具体 SKU 规格不拼入商品名。
- 客户收货信息只复制到本次订单快照，允许修改但不回写客户档案。
- 服务器版本与微信小程序版本分别记录和回滚，服务器部署不会被视为小程序包已经更新。
