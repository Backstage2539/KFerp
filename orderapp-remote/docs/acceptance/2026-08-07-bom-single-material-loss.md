# PR-585 BOM 业务名称与唯一原料损耗口径验收

## 用户确认口径

- BOM 删除“整体产出率 / 整体预期损耗”业务概念。
- BOM 没有原料损耗时不放大任何成本或投料。
- BOM 配置原料损耗后，它是唯一损耗来源，公式固定为 `净配方 × (1 + 原料损耗率)`。
- BOM 名称去掉编号、`生产 BOM` 和版本号等结构性前后缀，只保留业务名。
- 历史已冻结单据和价格快照不回算。

## BOM 名称统一

- 名称清洗兼容 `BOM-000659` 与 `BOM000643` 前缀，以及尾部 `生产 BOM / V001`、`生产 BOM`、`Production BOM` 和单独 `BOM`；清洗幂等且不得生成空名称。
- 列表和详情只展示业务名，BOM 编号、版本仍作为独立字段保留并可参与搜索。
- 新建、修改和复制 BOM 均在应用层执行同一清洗语义，避免以后重新写回结构性前后缀。
- 2026-08-07 通过现有业务 API 清洗开发环境 128 条、生产环境 149 条；复查残留均为 0，BOM 总数分别保持 149/168，启用/停用状态变更数均为 0。
- 两个环境分别新增 128/149 条 `production_bom/update` 操作日志；回滚映射为 `/opt/stacks/erp/backups/bom-name-normalization-20260807T235317.json` 和 `/opt/stacks/erp-production/backups/bom-name-normalization-20260807T235348.json`。
- 示例：开发 `BOM-000659`（id 8315）和生产 `BOM-000659`（id 30）的当前名称均为 `ALO TOH#1`，状态仍为 active。

## 修复前复现

开发和生产的 `BOM-000643` 当前发布版本均保存 `yield_rate=0.8` 与 `material_loss_rate=0.2`。曲奇 1kg 的原料净成本为：

`54 × 75% + 45 × 25% = 51.75元/kg`

旧链路连续使用两层除法，再加冻结工序：

`51.75 ÷ 0.8 ÷ 0.8 + 2.04 + 0.0667 + 0.5 = 83.466075 → 83.47元/kg`

同名价格计算模板不产生该数值；`83.47` 在进入模板加价、其他成本和税费前已经形成。

## 目标结果

- BOM 物料成本：`51.75 × 1.2 = 62.10元/kg`。
- 标准工序成本：`2.04 + 0.0667 + 0.5 = 2.6067元/kg`。
- 标准制造成本：`62.10 + 2.6067 = 64.7067 → 64.71元/kg`。
- 新生产计划的原料需求使用同一加耗公式；0 损耗时等于净配方。
- 旧 `yield_rate/expected_loss_rate` 不参与当前计算，但历史冻结值不被批量改写。
- 已从页面移除的旧行业计算预览 API 固定返回 `410 Gone`，不再允许客户端损耗率绕过 BOM。
