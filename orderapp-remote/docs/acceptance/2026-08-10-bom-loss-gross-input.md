# PR-592 BOM 原料损耗按总投料损耗率反算验收

## 当前口径

- BOM `material_loss_rate` 是当前成本和新生产需求的唯一损耗来源。
- 损耗率表示损耗数量占总投料数量的比例，因此 `总投料 = 净用量 ÷ (1 - 损耗率)`。
- 整体产出率、商品预期损耗、价格模板损耗和临时试算损耗不参与第二次放大。
- 历史工单、库存流水、已发布价格表、订单和冻结物料快照不回算。

## 初晓复现与目标

- 商品：初晓；价格模板：熟豆24磅模板-正常-418。
- 哥伦比亚 BOM组成：25%；BOM 原料损耗：19.5%；物料成本：78元/kg。
- 修复前加法口径：`25% × 1.195 × 78 = 23.3025元`。
- 目标损耗后用量：`25% ÷ (1 - 19.5%) = 31.0559%`。
- 目标折算成本：`31.0559% × 78 = 24.2236元 → 24.22元`。

## 自动验证

- 成本领域、价格试算 SQL/明细、新生产计划、物料需求、WIP、领料和新工单使用同一分母公式。
- 0 损耗不放大；非法或大于等于 100% 的损耗安全归零或被现有保存校验拒绝。
- 新物料快照写入 `loss_calculation_mode=yield_denominator`；旧 `additive` 与无标记快照保持冻结口径。
- 浏览器、API 和业务验收按 Van 要求不执行，由 Van 在 development 人工验证。
