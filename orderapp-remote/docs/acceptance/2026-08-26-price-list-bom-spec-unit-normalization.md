# 价格表 BOM 规格身份与单位归一验收（PR-611）

## 范围

- 修复旧价格表行将父商品写入 `product_id/sku_id` 导致发布提示“SKU 未在规格选择中”。
- 修复旧平铺行带 `1Kg` 等展示单位、而当前 BOM 规格库存单位为“袋”时的批量试算失败。
- 不写入生产价格表、订单或库存测试数据；只验证代码、接口和只读下单链路。

## 自动验收

- Go：单选 legacy 子 SKU 与单选 BOM 规格的旧父行均可保存/发布，身份分别归一到具体子 SKU 或父商品+BOM 规格；多规格和真正未选择规格仍阻断。
- Go：商品价格试算传入旧报价单位 `1Kg` 时，已选 BOM 规格仍返回其库存单位“袋”，不再返回单位不一致错误。
- Vue：价格表预览分组、平铺行和批量试算请求统一归一 BOM 规格身份；BOM 试算结果覆盖旧 `price_unit/inventory_unit` 并固化 `袋→袋` 换算。
- 全量门禁：Go/Vue 测试和 Vite 构建通过，既有 chunk-size 与 Node/pdfjs 仅为非阻断警告。

## 环境验收

- development 与 production 均通过登录页、未认证接口 401、认证订单录单表单和价格表只读接口检查。
- 生产不执行价格表发布或订单写入；正式发布与下单由业务人员按当前价格表手工验收。

## 业务操作

重新打开价格表生成草稿后，确认选中的 BOM 规格仍显示正确规格；点击“重新试算失败项”或重新生成预览，核对最终价单位显示 BOM 规格库存单位（例如 `/袋`），再发布价格表。小程序录单选择该商品及规格时，应读取刚发布快照的同一规格、单位和价格。
