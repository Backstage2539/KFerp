# 商品复制与 BOM 规格主体组件验收记录

## 范围

- 复制商品档案生成独立公共主档副本，不复制客户归属、行业字段、价格、BOM 或 BOM 规格单位字段。
- 商品身份编辑只提交名称、商品类型、备注等身份字段；已由 BOM 维护的单位字段保持原值，旧客户端直接提交单位字段仍返回 `product_unit_owned_by_bom_spec`。
- 商品生产 BOM 的规格模板主体支持物料，或商品加已发布 BOM 规格。商品主体固定用量；比例或原料损耗模板必须选择物料。

## 自动验证

- `go test ./...`
- `node --test frontend-vue-shell/src/lib/product-settings.test.js`
- `node --test frontend-vue-shell/src/lib/bom.test.js`

覆盖点包括身份字段不改写旧单位、复制不复制单位模板和客户归属、旧 `main_input_material_id` 兼容、商品主体组件结构化校验、已发布规格校验、比例/损耗模板拦截、前端主体组件选择与请求载荷。

## 人工复核步骤

1. 在商品档案复制任意商品，点击新商品名称改名；名称保存成功，规格/条码/库存单位仍由默认已发布 BOM 维护。
2. 新建商品生产 BOM，选择规格模板，在“规格主体组件”选择“商品（已发布 BOM 规格）”，再选择商品及规格；保存后检查版本详情中的 `main_input_component`。
3. 使用带比例或原料损耗的模板选择商品主体，保存应提示“商品规格主体只能使用固定用量”；改选物料后可继续。

本次只包含代码、测试和操作手册更新；不执行业务数据纠正，也不部署开发或生产环境。
