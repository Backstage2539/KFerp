# PR-649 生产计划三步工作台与草稿重算

业务范围：在 PR-648 多层生产、半成品备货、在途供应和分批入库基础上，重构生产计划的用户工作台。开发环境交付；正式环境不在本次范围，Van 保留最终业务验收。

## 实现结果

- 页面改为 `选需求 → 核对缺口 → 安排生产` 三步。选需求支持商品/客户/订单搜索、商品与规格三态选择、订单客户数量明细和具体配置异常。
- 缺口核对先显示结论，再分为“商品缺口”和一个统一“生产用料”清单。生产用料显示需要、现货、在产、剩余缺口及需制造/待补料/在产覆盖/库存满足，不向计划员展示 BOM 层级和依赖术语。
- 安排生产保留来源仓、货主、工位产能拆分、提交工单与撤销草稿。草稿生成后先展示摘要，由计划员主动安排生产。
- 新增草稿原单重算：返回修改需求后以原计划 ID、计划号和并发版本更新；保留身份完全兼容的目标仓、来源仓和工序拆分，变化部分重新确认。重复请求幂等，旧版本冲突返回 409，写入操作日志。
- PR/DEV 进度表和生产手册同步更新。
