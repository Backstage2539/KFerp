# PR-666 客户录单规格直选与价格表按钮合并验收证据

## 实现结果

- 发布价格行只有 `effective_sales_spec` 快照身份时，服务端仍恢复对应 BOM 规格及版本行；目录、自动核价和只读价格表共用该身份与真实名称。
- 一件代发和现货下单选中商品后，在录单行内直接展示并选择全部可下单规格，不再打开规格弹层或显示“默认规格”占位文字。
- 价格表预览只显示真实规格；规格资料确实缺失时显示“规格待维护”。
- ERP 两个用途保留独立下拉框，共用一组“保存 / 取消”。保存提交两项当前选择；取消解除两个用途的当前指定；解除单个用途时选择“未指定”后保存。

## RED / GREEN

- RED：应用测试重现发布快照只有 `effective_sales_spec` 时目录、预览和核价丢失 BOM 规格；小程序测试重现占位文字、规格弹层；Vue 源码测试重现两套重复按钮。
- GREEN：`mini_order_entry_ui_test.go` 覆盖真实规格恢复、排序、预览与核价；小程序工具及页面测试覆盖占位文字清理和行内直选；Vue 测试覆盖唯一“保存 / 取消”操作组。
- 自动校验：Go 全仓测试通过；Vue 1243 项、小程序 256 项测试通过；小程序类型检查、Vue 构建和微信小程序 development 构建通过。
- 小屏检查：390px 宽度下，规格按钮自动换行，四列价格预览和共用“保存 / 取消”均无横向溢出或遮挡。
- 双环境发布证据以本次最终交付记录为准。
