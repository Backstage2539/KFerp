## 修复范围

- 产出物料传递分类 ID，通过已有分类服务与外层事务共同校验、写入和审计；无效分类回滚。
- 根层档案参加分页，不再清空；大类总数仍包含子类，根层与子层不重复计数。
- 当前档案摘要增加 created/reused 来源，按正式 ID 合并；新建规格继承本次生成 BOM 的来源，执行快照及历史名称不改写。
- 分类选择复用当前功能启用的分类，显示完整层级，支持折叠、全部展开/收缩、搜索和祖先路径。
- 在预览中复用发布时的工艺成本产能校验，仅检查本次实际采用的工艺，合法覆盖不受被覆盖的失效路线阻止。
