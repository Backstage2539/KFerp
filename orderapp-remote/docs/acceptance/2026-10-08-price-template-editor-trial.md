# PR-686 价格模板编辑界面试算

## 需求和验收口径

在商品价格表的平铺价格行打开“编辑价格模板”时，可选择当前表已选商品与规格，并用未保存的完整模板参数自动试算。试算只读，不写模板、价格行或已发布快照；只有点击保存才更新全局模板和按当前行为重算受影响的草稿价格行。
