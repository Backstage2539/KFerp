# PR-743 代发入口与收件地址验收

## 范围

- 履约运营台代发页直接显示库存代发、无库存代发入口，按客户开通的场景启用；库存代发保留下单到库存和权益不足补购。
- 删除旧履约导入页面、专用前端代码和五个旧履约导入接口；历史数据及实际运费等功能共用的底层记录和服务保留，寄件回传与实际运费导入入口不变。
- ERP 代发表单只从地址簿选择或维护已保存地址，单行展示收件信息；客户侧共用表单保留其既有操作。去掉 ERP 手动核对按钮，点击提交仍自动请求服务端核验并使用报价凭证。

## 测试与证据

- RED：新增 Vue 回归先失败于旧导入界面仍存在及旧草稿不要求地址簿；新增接口测试先失败于五个旧导入接口仍可访问。修复后对应测试通过，旧接口均返回 404。
- 运行测试验证选择地址保留省市区、电话号码及商品，未保存地址不能使用；自动核价携带凭证，重复点击只创建一次，库存不足只提示补购并不创建订单。客户范围接口和原库存补购测试继续通过。
- `scripts/verify_kferp.sh frontend`：1643 项通过，Vue/Vite 构建通过；`scripts/verify_kferp.sh backend`：全 Go 包通过；`scripts/verify_kferp.sh changed` 通过。旧导入 UI 和旧接口的源码静态断言已改为验证新行为，历史服务与库存权限校验保留。
- 手册入口仍为 Vue 客户履约手册，源文档 `docs/OP_MANUAL_CUSTOMER_FULFILLMENT.md` 已更新当前操作并将旧导入说明标为历史资料。
