# PR-742 运费核算、库存代发与费用筛选验收

## 范围

- 修复 ERP 录单和员工小程序报价结果更新引发重复运费核算；手填、包邮、恢复自动及旧单保护沿用现有流程。
- 履约运营台库存代发可主动下单到客户库存，缺口补购及无库存代发沿用原流程。保存购货单后返回代发草稿并刷新目录。
- 客户费用按本月、上月、自定义或所有未付筛选。所有未付按 ERP 未付来源归集，合并已出账和未出账余额、排除预估运费与已收清来源；导出不受分类和分页影响。

## 验证

- RED：挂载 ERP 和员工小程序的真实运费组件，输入稳定后各自分别在 1.7 秒和 2 秒内发起 4 次报价，期望各 1 次；改用稳定的逐字段监听后 GREEN。开发环境的现有客户未配置有效运费模板，因此线上只读试算返回配置提示，不能作为成功报价或现场循环复现的证据。
- 代发：组件运行测试覆盖主动购买带入客户仓库、保留草稿和原缺口补购入口。未提交真实订单。
- 未付：隔离 PostgreSQL 验证跨月部分付款、出账后新增收款、已收清账单、已付订单的未付独立服务费、实际运费、退款调整及其他客户隔离；与 ERP 未付汇总一致。旧总额字段订单仍归入原订单。负向退款调整按现有 ERP 汇总口径处理，不另行创建一条正向欠款。
- HTTP 测试验证身份绑定、未付参数、非法参数与冲突日期拒绝、导出忽略分类及分页。
- 费用组件测试验证本月默认、所有未付、分类切换及下载参数；日期测试覆盖跨年和闰年边界。Excel 测试验证数值与未付列；多页中文 PDF 检查了表头、余额和页码。
- `scripts/verify_kferp.sh backend` 通过；ERP 前端测试 1646 项与构建通过；小程序 73 个文件 437 项测试、类型检查及开发构建通过；`scripts/verify_kferp.sh changed` 通过。后端第一次全量检查发现旧测试写死“折后”文案，已更新为兼容当期和未付标签并复验通过。
