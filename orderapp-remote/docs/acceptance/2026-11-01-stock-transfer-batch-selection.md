# 库存转仓按实际规格和批次选择

- 产品需求：PR-STOCK-TRANSFER-BATCH-SELECTION。开发项：DEV-STOCK-TRANSFER-BATCH-API、DEV-STOCK-TRANSFER-BATCH-UI、DEV-STOCK-TRANSFER-BATCH-RELEASE。
- 范围：普通库存转仓；生产领料、其他入库和出库流程沿用原规则。转仓每行选择来源仓、商品或物料、已有规格和来源批次，只填写一个数量；显示规格和批次账面、可转数量。
- 权益与异常：按质检状态、货主、有效批次预留、客户寄存、实际批次和汇总校验；无法确认归属的未绑定批次预留、无批次库存或批次汇总差异提示核对。过账重查并锁定，整单事务回滚；无自动补建批次。
- 规格与数量：历史 BOM 批次使用自身规格快照；整件按件，物料按库存单位，真实散装按克。目标批次保留来源关系，明细展示来源和目标批次。
- 自动验证：隔离 PostgreSQL 事务、库存服务和 HTTP 接口测试；前端交互测试、全量前端测试和构建；记录来源/目标批次、重复提交、多行超量、预留与不一致、撤销和并发锁。
- 页面检查：隔离浏览器测试数据验证来源仓、商品、规格、必选批次、库存与可转量、散装克数；测试页拒绝任何业务写入。
- 开发库部署前只读核对：成品仓 29 组库存，14 组与批次汇总不一致，其中 5 组没有批次；全库 3 条有效预留未绑定完整批次。相关库存需核对后才能转仓，本需求不修复业务数据。
- 用户操作说明：`docs/OP_MANUAL_STOCK.md#库存单据`、`docs/OP_MANUAL_INVENTORY_MATERIALS.md#库存作业`，经操作手册入口展示。
- 开发环境版本、部署与验收：待部署后补充；真实业务转仓尚未操作，等待 Van 业务验收。
