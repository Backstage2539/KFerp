# 转仓商品按来源仓库存选择

- 问题：库存转仓商品下拉框使用全部商品档案，与出库仓库存无关，并受初始分页限制。
- 范围：库存转仓的商品/SKU 按每条明细选定的出库仓读取库存全部分页，商品按库存记录去重，BOM 规格仅显示该仓该商品有库存的当前商品规格；切换来源仓清除所选商品。库存和质检以提交时校验为准。其他库存单据仍使用原商品档案搜索。
- 生产只读核对：成品仓现存初晓 227g、小菠萝 454g、曜石 2.0 的 227g、454g、1KG、500g；批次合计与库存余额一致，规格均存在当前发布版本。喜沁仓库为独立客户仓。未创建或过账单据。
