# 履约代发地址地区识别

## 范围与数据边界

喜沁咖啡所选旧地址的行政字段为云南省、大理市、大理古城。大理市是大理白族自治州下的县级市，大理古城是地址地点而非区县名称；原字段按省、市、区逐级运费核算时被拒绝。正式地址簿、订单草稿及真实代发订单未修改或提交。

对唯一且无冲突的县级市错位旧地址，仅在原地区规则无法识别时报价兼容，使用规范地区计算运费，同时保留完整原始收件地址。原本可成功的旧文本模板、包邮、标准地址、存在其他区县冲突和不明确地区继续沿用原行为。员工和客户门户分别使用代发权限下的只读地区目录；编辑地址由用户确认保存。
