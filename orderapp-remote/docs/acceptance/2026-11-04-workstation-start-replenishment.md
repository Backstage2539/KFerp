# 工位待开工补料与页面更新提示

## 验收范围

- 新策略首道简化工序的开工预览展示实际 WIP 缺口，可进入既有领料抽屉；冻结预留待领量与开工缺口分别展示，人工核对实际领料量。
- 领料沿用既有权限、来源批次、货主、可用库存、事务和操作日志；领料后重新读取工位和开工建议，再由人员确认开工。不得自动领料、开工或完成工序。
- 旧页面误提交完工时得到刷新与开工指引；新版页面发现前端更新时提示先保存内容，再由用户决定何时刷新。
- 请求结果未确认时必须保留同一次请求标识并重试，不允许悄悄改成新的领料请求。
