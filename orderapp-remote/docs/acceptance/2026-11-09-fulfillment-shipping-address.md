# PR-753 履约出账收货地址与寄件重量

## 需求与安全边界

- 费用未出账、预览、已出账及 Excel/PDF/PNG 明细展示可核实的订单收货地址和对应运单结算重量。新账单冻结出账时地址；历史账单没有地址快照时，客户、费用来源及订单均一致才只读显示订单当前地址并标注来源。已有快照不覆盖。
- 预览后地址或重量变化须重新预览；重复出账请求维持原账单、金额和地址快照。

## 验证

- TDD：先复现地址缺失、未出账及预览缺明细、预览后地址变化仍可出账；实现后隔离 PostgreSQL 回归通过，覆盖跨客户、同客户错误订单、空地址、历史快照、重量变化和出账幂等。
- Vue 费用页面回归及生产构建通过；Excel/PDF/PNG 测试通过，PDF 示例人工查看长地址、单号、重量未重叠。
- 客户权限和账单应用层测试通过；操作手册已更新。
- 正式环境按用户授权重新上传 4 份原寄件表，7 条已处理记录补入 P 列结算重量；每批均有补录操作日志，未新增运费、运单或库存扣减。示例运单 SF1224903286779 的已出账明细重量为 7.000 kg。原表收件地址脱敏，历史地址按来源标记，不能认作当时发货地址。

## 待用户验收

- 在正式环境核对实际费用清单、地址来源及导出。
