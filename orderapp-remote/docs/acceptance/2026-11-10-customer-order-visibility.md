# 指定客户订单的小程序可见性

- 每个客户与订单组合使用既有 `app_config` 独立键 `customer_portal.hidden_order.<客户ID>.<订单ID>`；值为 `hidden` 时不在该客户的小程序显示，设置为 `visible` 即恢复。不存在标记时维持原有展示行为，不新增表或迁移。
- 可见性标记仅影响订单列表、首页统计和客户订单访问；ERP 订单、账单、客户库存权益及生产历史均不因此改变。受控修改与操作日志应在同一事务提交；客户页面没有修改入口。
- 隔离 PostgreSQL 的 RED：写入既有配置表的隐藏标记后，旧实现仍返回目标订单，专项测试失败。
- GREEN：按客户和订单精确匹配后，专项测试验证其他客户隔离、列表／首页／指定订单访问一致、恢复、账单及权益不变；旧数据库和查询错误的兼容性测试通过。
- 在隔离数据库运行完整 customerportal 测试包时的 26 项失败，已对照未修改的 `origin/develop` 逐项复现；不将其计为本功能通过。业务验收另行记录。
