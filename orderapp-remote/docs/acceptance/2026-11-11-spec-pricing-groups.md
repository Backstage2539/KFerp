# 规格计价组与客户多规格价格表验收

- 产品需求：PR-SPEC-PRICING-GROUPS-20261111。
- 状态：**功能分支整合验证通过；环境部署及业务验收待完成。**
- 边界：不修改生产 BOM，不补建 50g 生产规格；生产环境孟豆豆的正式价格表由业务人员选择实际模板和来源后发布。现网小程序安装包不在本次变更范围。

## 验证清单

- [ ] 规格模板从商品菜单进入；BOM 和组配置中的快捷入口可往返，刷新后无过期返回入口；模板原有发布及下发功能、数据和权限保持正确。
- [ ] 可新建、编辑、停用规格计价组；一个已发布规格模板中每个选中规格均选择有效价格模板；操作日志记录新增、修改、停用，权限不足不能写入。
- [ ] 商品价格表按商品、最近分类、上级分类、表默认的顺序继承整组；选组自动选择全部目标规格；模板不一致、缺规格或成本不可用时保留商品并阻止发布。
- [ ] 从公共已发布价格表选品，默认全选、支持调整；补齐客户商品后创建新的命名草稿，不改变现有客户名称、货号或其他命名价格表；保存失败有明确反馈。
- [ ] 同一商品 227g、100g、50g 分别引用不同价格模板，试算价格和单位正确；完成组修改、手工调整、复制、刷新和切表后结果按操作规则恢复。
- [ ] 前端与服务端均拒绝组修订、规格来源或 BOM 发生变化后的过期发布；缺少组内规格和停用价格模板不可发布。
- [ ] 发布一件代发价格表并明确指定后，各规格按冻结的固定单价与数量计算；后续更新组和发布新版不回改旧单、已发布价格表及历史订单。
- [ ] PDF/图片预览与发布价格表规格、单位和金额一致。页面和手册入口可访问，成本核价手册、生产/BOM 手册与本验收记录一致。
