# 财务每日经营流水与利润曲线验收

- 需求：PR-767-FINANCE-DAILY-LEDGER；开发任务 DEV-PR767-COST、API、UI、DELIVERY。
- 口径：销售收入及对应实际销售成本按订单日期，费用及冲减按各自发生或过账日期；缺少可靠成本显示待核算。该页面不是实际收付款流水。
- 范围：月报、财务首页及每日明细一致；新月结冻结每日汇总和明细，旧月结缺少快照时提示不可用。
- 验证：隔离 PostgreSQL 16 上财务应用、仓储、HTTP 和权限包通过；覆盖订单批次、部分完工、未知与零成本、退货、客户范围、月结快照、冲减和分以下金额尾差。无业务数据库的后端全套通过；Vue 全量 2022 项及生产构建通过。
- 页面：隔离数据在桌面 Chrome 中验证曲线、待核算提示与流水；DOM 回归覆盖日期、筛选、分页、来源跳转及返回。
- 现有限制：已结账的旧快照没有每日／客户明细时不可回算；成本无法可靠归属的历史订单显示待核算。核对生产现状发现本月历史订单缺少直接的出库或生产分配关联，不能据此宣称真实利润已完整计算。
