# 服务号订单通知接收人管理（PR-WECHAT-SUBSCRIPTION-ADMIN-20261112）

## 范围

- 管理员按客户、员工或手机号查询，逐小程序账号查看服务号绑定、关注、通知开关和所选项目；无绑定时不臆测关注状态，同一客户多个账号分别显示。
- 针对单个小程序身份提醒下次进入时重新选择，不主动发送微信消息或改变当前用户偏好。没有小程序账号的人员需先登录并关联身份。
- 用户本人完成关注绑定和通知选择。客户档案手机号仅用于搜索和联系，不能据此认领微信、推断关注或代开通知。通知发送仍按既有客户数据范围及员工权限校验。
- 页面区域名为“客户与员工通知状态”。同一账号可能关联多个微信，展示“关联记录”“当前绑定”“已关注”和“绑定通知开启”数量；关联记录是现存记录，不能当作完整历史。仅当前绑定且已关注、通知开关开启者计入“绑定通知开启”；不能据数量推断所有接收人均已授权。
- “用户选择”反映本人选择，“绑定通知开启”反映当前符合条件的服务号绑定数量；应分别展示，不能把两者都开启解释为模板、事件和服务号自动发送总开关已经就绪或消息已经送达。没有当前绑定时关注状态为未知，不得推断已关注。
