# 工位卡片、投入齐套与工单详情（PR-767）

## 范围

精简工位卡片，以任务实际投入计算剩余缺口，完善工单冻结信息与工位定位。现场业务记录仅作只读核对，写入验证在隔离数据上进行。

## 验证进度

- RED/GREEN：任务级投入、八单数量及 0.230 kg 尾单精度；工位卡片及窄屏用料标签。
- 隔离 PostgreSQL：任务开工后只读查询不新增库存流水；部分退料、重复物料、共享库存、货主／仓库／规格隔离、来源成本缺失和已投入成本守恒。
- 隔离 HTTP：真实开工、退料和详情成本；冻结工单后发布新版 BOM，详情仍返回原版本及用料。八单 209.230 kg 与 WIP 0.270 kg 为服务层模拟，不冒称八单数据库端到端。
- Go 全包无业务数据库测试通过；隔离仓储全包一项历史夹具缺 `jc.scheduling_mode`，原始 main 同一命令可复现。

- 正式发布和用户业务验收待完成。
