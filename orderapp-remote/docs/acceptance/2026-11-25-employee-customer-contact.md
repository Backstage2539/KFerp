# 员工新增客户联系方式必填（PR-774）

员工小程序「简易 ERP → 录单 / 客户维护」和网页「录单 → 新增客户」「客户档案 → 新增客户」共用相同的新增规则。每次清空联系人、联系电话或联系地址中的一项，保存后应提示补齐相应字段。输入纯空白同样拦截，联系电话可填写手机号或座机。补齐后可保存并在录单页选中新客户。

- 实现前，两个创建接口的六个缺字段请求都到达测试写入层。实现后均返回 400 和对应字段，写入次数为零。用例为 `TestEmployeeCreateCustomerRequiresContactsOnBothAPIs`。
- 应用服务覆盖小程序销售、管理员与网页后台。新增使用联系资料，编辑既有档案沿用原规则。成功保存沿用原事务、负责人检查和操作日志。
- 小程序实际编辑组件验证逐项为空时阻止请求、资料完整后提交。Vue 录单抽屉验证空格和只有公司电话时提示缺少联系电话。
