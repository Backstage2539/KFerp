# PR-773 员工小程序取消订单

业务验收人 Van。操作入口见 [员工 ERP 手册](../OP_MANUAL_MINIAPP_EMPLOYEE_ERP.md)。

| 验证 | 结果 |
| --- | --- |
| 实现前 | Go 用例因取消入口缺失而编译失败。小程序两项用例因缺少原因和提交接口而失败。 |
| 员工接口 | 销售、管理员可提交。匿名、客户、缺少处理权限、超出本人订单范围、空原因、其他原因及额外参数均被拒绝。 |
| 隔离 PostgreSQL | 普通订单取消后保留原单。重复提交只生成一张处理单和一条提交日志，原因和员工身份可查。已收款、部分发货、未处置运费以及其他员工订单均受到保护。共用提交路径的日志失败回滚测试通过。 |
| 小程序 | 原因和值通过接口契约测试。编译后的详情页使用隔离订单响应验证无权限隐藏、保留订单、按原因取消、连续点选只提交一次及成功刷新。 |
| 构建 | Go 全包测试，小程序测试、类型检查与开发版构建，网页手册入口测试和 Vue 构建。 |

开发版真机验收待 Van 完成。可使用一张未收款、未发货且无待处置费用的开发测试单，选择原因后核对详情、列表和后台操作日志。
