# PR-775 员工录单与商品选择器

- 使用员工入口，在同一微信开发者工具模拟器、同一网络与账号下记录首次进入、重复进入、打开已加载目录及选中核价延时，各 20 次。目标为重复进入 P95 ≤1 秒，打开选择器至可搜索 P95 ≤300 毫秒。反馈基线约 3 秒，模拟器验收待记录。
- RED：新接口测试得到 HTTP 404。小程序缓存测试因缺少版本缓存实现失败。
- API：首次基础资料与客户商品目录分别加载，同版本仅返回版本确认；默认表解析后的显式选择命中同一版本。缓存命中仍要求员工鉴权。旧版表单继续提供完整响应。
- PostgreSQL：在隔离 schema 验证草稿发布、已提交与回滚事务、版本撤回、不同客户隔离、收件资料更新与停用客户。修改客户电话只影响基础资料。
- 小程序：覆盖并发检查、失效会话、切换客户、草稿恢复、保留价格和冻结历史规格；手册入口为「员工小程序 ERP 手册」。
- 验收操作只需打开录单、选择客户与商品。业务验收人 Van。
