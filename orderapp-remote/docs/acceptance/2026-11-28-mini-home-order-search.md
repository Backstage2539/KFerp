# PR-776 员工首页选客户与续填草稿

## 员工操作

在员工首页点「录单」，可直接输入客户名称、拼音或首字母。系统并行读取基础资料和本人最新草稿。有草稿时优先恢复，没有草稿时点选已核对的客户后进入录单表单。操作步骤见[员工小程序手册](../OP_MANUAL_MINIAPP_EMPLOYEE_ERP.md)。

## 功能验证

- 首页 Vue 交互测试在原实现上出现四项失败。覆盖搜索词回显、客户及草稿读取时序、草稿优先、读取失败原位重试、关闭后重进、会话失效、首次授权、双击、导航失败重试及切页中误触遮罩。
- 录单页运行时测试首轮有五项失败。覆盖一次性交接、复用选客及核价请求、原样恢复草稿、允许新增客户、权限撤回、失效交接回退、编辑和复制。
- 小程序 99 个测试文件共 603 项通过，Vue 类型检查和微信开发环境构建通过。网页端 2,083 项测试通过，Vue 生产构建通过。Go 全量测试通过，含员工录单和草稿 HTTP handler 权限及响应契约。
- 服务端沿用现有业务接口。打开搜索及选客只读取数据；客户保存、草稿保存及正式提交继续走原有写入与审计路径。

## 耗时与真机验收

对同一员工、数据集、设备和网络分别比较新旧包，记录首进与重复进入。每个场景各 20 次，P95 取排序后第 19 个值。

| 指标 | 验收条件 |
| --- | --- |
| 点录单至输入首个字符并读回 | 热态 P95 ≤ 300 ms |
| 点录单至匹配客户可选 | 热态 P95 ≤ 1,000 ms |
| 选择客户至表单可继续选品 | 同条件 P95 不高于旧包，同时对比从首页开始的总用时 |
| 重复打开选品器至可搜索 | P95 ≤ 300 ms，目录未变化时完整目录请求为零 |

开发者工具与前台真机分别出具结果。开发构建的功能测试完成，真机通过后安排正式发布。
