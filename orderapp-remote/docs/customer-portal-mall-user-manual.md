# 客户门户商城操作手册

## 适用范围

客户门户商城用于给 C 端客户在小程序下单。ERP 后台负责配置客户是否进入商城、维护商城商品和图片；小程序客户负责浏览商品、加入购物车并提交订单。提交成功后，订单进入 ERP 现有订单列表。

## ERP 后台配置

### 1. 开通客户商城

1. 打开 `客户门户配置`。
2. 找到目标客户。
3. 在 `小程序首页` 中选择 `商城`。
4. 在能力列表中勾选 `商城下单`。
5. 按需选择小程序主题。
6. 点击 `保存配置`。

如希望客户继续使用订单处理界面，把 `小程序首页` 改回 `订单处理`；如不允许客户访问商城，取消勾选 `商城下单`。

### 2. 上架商品

1. 打开 `商城管理`。
2. 点击 `新增商品`。
3. 在 `ERP 产品` 中选择已有产品。
4. 填写标题、副标题、描述、规格、售价、模板、状态和排序。
5. 右侧 `商城预览` 会随表单实时变化。
6. 点击 `保存商品`。
7. 保存后可上传图片；图片上传成功后会生成 `/assets/mall_products/...` 图片 URL。
8. 将状态改为 `上架` 后保存，小程序商城才会展示该商品。

### 3. 调整或下架商品

1. 打开 `商城管理`。
2. 在左侧选择商品。
3. 修改字段后点击 `保存商品`。
4. 若暂时不展示，状态改为 `草稿` 并保存。

## 小程序客户下单

1. 客户登录小程序。
2. 如果该客户配置为商城首页，会直接进入商城；否则在服务首页点击 `商城下单`。
3. 浏览商品，点击 `加入`。
4. 在购物车中增减数量。
5. 填写收件人、手机号、收货地址和备注。
6. 点击 `提交订单`。
7. 成功后小程序提示订单号，ERP 订单列表出现来源为 `mall` 的订单。

## 验收重点

- 客户 A 配置商城首页后，登录直接进入商城；客户 B 保持订单处理首页不受影响。
- 未启用 `商城下单` 能力的客户无法访问商城数据。
- 后台上传图片后，小程序可正常展示。
- 小程序购物车数量与 ERP 订单明细一致。
- 商城订单进入 ERP 订单列表后，可沿用现有生产、发货、销售单和财务流程。

## 当前已知边界

- 第一版商城不包含在线支付、优惠券、库存占用和会员营销。
- 商品上架基于现有 ERP 产品，不在商城管理里新建产品主档。
- 商城订单提交后进入 ERP 订单流程，后续状态仍由 ERP 后台处理。
