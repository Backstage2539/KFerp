# 出库单用户手册

## 维护出库单

| 区域 | 操作 |
| --- | --- |
| 入口 | 在订单列表中，订单发货状态为“已发货”后点击“出库单”。 |
| 出库信息 | 维护出库日期、出库仓库、发货方式、快递单号和备注。 |
| 预览 | 保存出库信息后刷新预览，确认出库单号、客户、收货地址、商品明细和出库仓。 |
| 生成 PDF | 预览确认后点击“确认生成 PDF”；首次生成 V1，再次生成 V2，不覆盖旧版本。 |
| 下载 | 使用“下载最新版”给仓库、物流或随货打印；历史版本用于追溯。 |
| 分享到微信 | 已生成出库单 PDF 后点击“分享到微信”；系统会调起系统分享面板直接发送 PDF 文件。浏览器不支持直接分享文件时，按提示下载最新版后手动发送到微信。 |

## 验收检查

- 未发货订单不能生成出库单预览或正式出库单。
- 出库单预览不会新增版本。
- 确认生成后新增一个出库单版本。
- 历史版本和最新版都能下载 PDF。
- 点击“分享到微信”后会直接分享出库单 PDF 文件，不把分享链接作为默认分享内容。
- 出库单 PDF 与销售单 PDF/图片使用同一个 `/api/share-resources` 分享接口定位文件，并通过同一个前端 helper 分享文件。
