# 财务月结用户手册

适用范围：咖啡烘焙厂、咖啡贸易商、咖啡壳豆加工厂和综合咖啡工厂的月度经营复盘。

## 1. 常用入口

| 菜单 | 用途 |
| --- | --- |
| 财务管理 -> 财务首页 | 看当月收入、成本、费用、毛利、净利、税费估算和异常提醒 |
| 财务管理 -> 费用管理 | 补录房租、物流、人工等期间费用，或补录应计入主营成本的费用 |
| 财务管理 -> 月度结账 | 生成月度结账快照，结账后录入金额调整 |
| 财务管理 -> 经营报告 | 查看老板简报、利润明细、税费明细，导出 PDF 和 Excel |
| 财务管理 -> 财务设置 | 设置企业类型、纳税人类型、税率和锁账模式 |

## 2. 财务设置

先进入 `财务管理 -> 财务设置`。

1. 选择企业类型：咖啡烘焙厂、咖啡贸易商、咖啡壳豆加工厂或综合咖啡工厂。
2. 选择纳税人类型：小规模纳税人或一般纳税人。
3. 按实际管理口径维护税率、免税阈值、附加税率、企业所得税率和小微优惠参数。
4. 保存设置。

税费估算用于经营管理，不等于正式纳税申报结果。

## 3. 财务首页

入口：`财务管理 -> 财务首页`

1. 选择月份。
2. 查看不含税收入、毛利、净利和税费估算。
3. 查看含税收入、主营成本、期间费用和结账状态。
4. 如有异常提醒，先回到对应业务补齐数据。

## 4. 费用管理

入口：`财务管理 -> 费用管理`

新增费用时填写：

| 字段 | 说明 |
| --- | --- |
| 日期 | 费用发生日期，系统按日期归属月份 |
| 类别 | 房租、物流、人工、耗材、外协加工费、银行手续费等；输入关键字可从候选项中筛选，也可直接输入自定义类别 |
| 金额 | 本次费用金额 |
| 归集 | 期间费用或主营成本 |
| 关联员工 | 可选；用于记录工资、报销、差旅、补贴等与员工相关的费用 |
| 付款方式 | 微信支付、支付宝、银行转账、对公银行、员工垫付、应付未付等；输入关键字可从候选项中筛选，也可直接输入自定义付款方式 |
| 备注 | 可选 |

费用列表会显示关联员工。点击列表中的员工名，页面会自动筛选出该员工相关费用；点击“清除员工”恢复查看全部员工费用。

类别和付款方式输入框会先列出常用候选。空白时可查看完整候选，输入“银行”“耗材”“加工”等关键字时会模糊搜索候选项；候选不合适时保留手动录入。

结账后如果当前月份是强锁账，系统会拒绝继续新增同月费用。

## 5. 月度结账

入口：`财务管理 -> 月度结账`

1. 选择月份。
2. 确认收入、成本、费用、税费估算和净利。
3. 点击结账。
4. 结账成功后，月份状态变为已结账。

默认锁账模式是强锁账。结账后不要直接改来源单据，统一走结账后调整。

## 6. 结账后调整

入口：`财务管理 -> 月度结账`

结账后可以新增金额调整：

| 类型 | 影响 |
| --- | --- |
| 收入 | 调整不含税收入和毛利 |
| 主营成本 | 调整主营成本和毛利 |
| 期间费用 | 调整期间费用和净利 |
| 税费 | 调整税费合计和净利 |
| 其他 | 记录备查，不改变核心口径 |

调整必须填写金额和原因。新增调整后，报表状态变为已调整。

## 7. 经营报告

入口：`财务管理 -> 经营报告`

报告包含两层：

1. 老板简报：收入、毛利、净利、税费。
2. 明细表：利润表和税费估算表。

页面右上角可导出 PDF 和 Excel。系统页面仍是主要查看入口，导出用于对账、留档和发给外部会计。

## 8. 锁账模式切换

锁账模式有两种：

| 模式 | 说明 |
| --- | --- |
| 强锁账 | 结账后锁定来源单据，只允许结账后调整 |
| 轻确认 | 结账后仍允许补录来源单据，适合早期试运行 |

切换入口只对白名单用户显示。即使前端入口被绕过，后端接口仍会校验 `finance.close_mode.manage` 权限和白名单。

白名单可由数据库财务设置保存，也可通过环境变量 `FINANCE_CLOSE_MODE_ADMIN_USERS` 配置，多个用户用英文逗号分隔。
