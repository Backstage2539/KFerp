# 录单用户手册

## 日常流程

```mermaid
flowchart LR
  A[打开录单] --> B[搜索并选择客户]
  B --> C[确认来源和订单类型]
  C --> D[选择商品和规格]
  D --> E[确认自动梯度价或手动改价]
  E --> F[填写费用和备注]
  F --> G[保存订单]
```

## 操作要点

| 区域 | 操作 |
| --- | --- |
| 客户 | 在客户输入框输入客户名、拼音或首字母，选择后自动带入客户档案的默认来源和订单类型。 |
| 状态 | 新录订单默认付款状态为已付款，发货状态为未发货。编辑旧订单时保留原状态。 |
| 商品 | 在商品输入框直接搜索并选择商品，不再使用独立搜索框。 |
| 规格 | 常用规格为 36g、80g、100g、227g、454g、500g、1000g、2.5kg；选择商品后默认使用该商品第一个价格梯度的规格。 |
| 梯度价 | 选择商品后，明细下方展示该商品所有规格/数量梯度和单价；点击梯度可快速切换规格并重新计价。 |
| 单价 | 选择商品、规格、数量后自动匹配价格梯度；需要临时改价时直接编辑单价。 |
| 恢复自动价 | 点击单价右侧的 ↺，按当前商品、规格、数量重新匹配梯度价。 |
| 库存批次 | 保存前如果成品库存批次足够，系统会列出建议批次并询问是否使用。选择使用后订单进入“库存待发货”；选择不使用则按库存不足处理，进入生产计划。 |
| 顺丰发货 Excel | 录单页面只保存订单，不处理快递；订单生产完成、无需生产或库存待发货后到订单列表勾选订单生成顺丰发货 Excel。 |

## 验收检查

- 客户搜索支持名称、拼音和首字母。
- 商品明细只有一个商品选择输入框，可直接搜索商品。
- 新增订单的付款状态默认为已付款，发货状态默认为未发货。
- 商品规格覆盖 36g、80g、100g、227g、454g、500g、1000g、2.5kg。
- 选择商品后可看到所有梯度价格，并默认选中该商品第一个梯度规格。
- 价格会随规格和数量变化；手动输入单价后保存订单使用手动价。
- 成品库存充足时，保存前会提示可用批次；确认使用后订单生产状态为“库存待发货”。
- 拒绝使用现有批次时，订单不会占用该批次，后续在生产计划按库存不足处理。
- 保存订单后不出现顺丰发货 Excel 下载入口。
