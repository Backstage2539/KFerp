# 采购入库用户手册

## 流程

```mermaid
flowchart LR
  A[维护供应商] --> B[创建采购单]
  B --> C[收货入库]
  C --> D[生成原料批次和库存流水]
  D --> E[更新物料采购价]
```

## 操作要点

| 区域 | 操作 |
| --- | --- |
| 供应商 | 录入供应商名称、联系人、电话和地址；同名供应商会更新资料并保持启用。 |
| 采购单 | 选择供应商和物料，填写采购数量(g)、单价和备注后创建采购单。 |
| 收货入库 | 对待收货采购单点击收货入库；系统会调用原料入库能力生成原料批次、库存批次、原料仓库存和库存流水。 |
| 采购价 | 收货成功后，物料档案的采购价会更新为本次收货单价，用于后续成本核算参考。 |

## 验收检查

- 能新增供应商并在采购单中选择。
- 能创建采购单，并在待收货列表看到单号、供应商、物料、数量和单价。
- 对采购单执行收货后，收货记录展示库存批次号。
- 原料批次、库存流水和原料仓库存同步增加。
- 物料采购价更新为本次收货单价。
