# 销售单用户手册

## 销售单设置

| 区域 | 操作 |
| --- | --- |
| 公司名称 | 在设置里的“公司设置”维护，生成销售单时写入快照；销售单设置页不再维护公司名称。 |
| 个性化说明 | 用于包装、付款、售后等说明；只影响之后新生成的销售单。 |
| 收款方式 | 填写微信、支付宝、对公转账等文字说明。 |
| 公账收款设置 | 维护户名、开户行和账号；为空时销售单不显示公账信息。 |
| 收款码 | 可上传多个收款码，填写名称、说明和排序；预览和 PDF 会并排展示收款码图片。 |
| 公章 | 上传公章图片后，可点击“去除背景”生成透明 PNG；也可在设置页或销售单预览页拖动调整盖章位置，并在设置页调整公章大小，生成 PDF 时公章会盖在公司名称附近。 |

## 生成销售单

| 区域 | 操作 |
| --- | --- |
| 订单列表 | 每行“操作”列点击“销售单”会在当前页面弹出销售单抽屉，保留当前筛选和分页。 |
| 客户信息 | 生成前点击“客户信息”，右侧抽屉可维护客户公司名称、公司地址、联系电话、联系人、收货电话和收货地址。 |
| 销售单设置 | 在销售单抽屉内点击“销售单设置”，可右侧打开设置抽屉维护说明、收款方式、公账收款、收款码、公章位置和公章大小。 |
| 预览 | 页面会展示“销售单预览”，包含并排收款码、公账信息、公章、多行收款方式和多行说明；公章可直接拖动并保存位置；修改客户信息、公司设置或销售单设置后，先刷新预览确认内容。 |
| 生成 PDF | 点击“确认生成 PDF”后，系统按当前预览和设置生成新版本。 |
| 历史版本 | 同一订单重复生成会得到 V1、V2、V3；旧版本保留，最新版单独标记。 |
| 下载 | 可下载指定历史版本，也可下载最新版。 |
| 快照 | 已生成 PDF 固化当时的订单明细、金额、公司名称、客户公司信息、说明和收款信息。 |

## 验收检查

- 公司设置可保存公司名称，销售单设置可保存说明、收款方式、公账收款、多个收款码、公章、公章位置和公章大小。
- 订单列表点击“销售单”会打开销售单抽屉，不离开当前订单列表。
- 销售单抽屉内可打开销售单设置抽屉。
- 销售单页面右侧客户信息抽屉可以保存客户公司名称、公司地址和联系电话。
- 销售单页面先展示预览，刷新预览不创建历史版本，确认生成后才创建新版本。
- 历史版本下载和下载最新版都能返回 PDF，不出现 `invalid document id`。
- 销售单预览可直接拖动公章并保存坐标，刷新预览后位置不丢。
- 销售单设置页“去除背景”会把当前公章转换为透明 PNG。
- 销售单预览和 PDF 都能看到并排收款码、公账信息、公章和多行文本，公章盖在公司名称附近且不被拉伸。
- 公司设置公司名称未维护且客户公司名称为空时，生成 PDF 不报错，PDF 公司名使用客户名。
- 同一个订单第一次生成得到 V1，再生成得到 V2。
- 历史版本可以继续下载，最新版链接指向当前最新版本。
- 修改销售单设置后，旧版本不被覆盖；重新生成才使用新设置。
