# 销售单用户手册

## 销售单设置

| 区域 | 操作 |
| --- | --- |
| 公司名称 | 在设置里的“公司设置”维护，生成销售单时写入快照；销售单设置页不再维护公司名称。 |
| 公账收款设置 | 在“公司设置”维护公司地址、纳税人识别号、户名、开户行和账号；点击“一键复制公账收款信息”可复制给客户。 |
| 个性化说明 | 用于包装、付款、售后等说明；只影响之后新生成的销售单。 |
| 收款方式 | 填写微信、支付宝、对公转账等文字说明。 |
| 收款码 | 可上传多个收款码，填写名称、说明和排序；单个收款码会放大展示，多个收款码会自适应填充销售单空白区域；生成 PDF/图片时二维码会按可扫码尺寸放大。 |
| 公章 | 上传公章图片后，可点击“去除背景”生成透明 PNG；也可在设置页或销售单预览页按住公章拖动调整盖章位置，设置页松手自动保存，并在设置页调整公章大小，生成 PDF 或图片时公章会盖在公司名称附近。 |

## 生成销售单

| 区域 | 操作 |
| --- | --- |
| 订单列表 | 每行“操作”列点击“销售单”会在当前页面弹出销售单抽屉，保留当前筛选和分页。 |
| 客户信息 | 生成前点击“客户信息”，右侧抽屉可维护客户公司名称、公司地址、联系电话、联系人、收货电话和收货地址。 |
| 销售单设置 | 在销售单抽屉内点击“销售单设置”，可右侧打开设置抽屉维护说明、收款方式、收款码、公章位置和公章大小。按住公章拖动时不会跳走，松手自动保存；公账收款信息请到“公司设置”维护。 |
| 预览 | 页面会展示“销售单预览”，包含自适应收款码、公账信息、公章、多行收款方式和多行说明；客户公司地址会换行显示；公章可直接拖动并保存位置。修改公章位置、客户信息、公司设置或销售单设置后，先刷新预览确认内容，再重新生成 PDF 或图片。 |
| 生成 PDF | 点击“确认生成 PDF”后，系统按当前预览和设置生成 PDF 新版本。 |
| 生成图片 | 点击“确认生成图片”后，系统按当前预览和设置生成高清 PNG 图片新版本；图片版本和 PDF 版本分别记录。 |
| 历史版本 | 同一订单重复生成会得到 V1、V2、V3；旧版本保留，最新版单独标记。 |
| 下载 | 可下载指定 PDF/图片历史版本，也可下载最新版 PDF 或最新版图片。 |
| 分享到微信 | 已生成 PDF 后可点击“分享PDF到微信”，已生成图片后可点击“分享图片到微信”；系统会调起系统分享面板直接发送 PDF 或 PNG 文件。浏览器不支持直接分享文件时，按提示下载最新版后手动发送到微信。 |
| 快照 | 已生成 PDF 和图片都会固化当时的订单明细、金额、公司名称、客户公司信息、说明和收款信息。 |

## 验收检查

- 公司设置可保存公司名称、公司地址、纳税人识别号和公账收款信息，并可一键复制公账收款信息；销售单设置只保存说明、收款方式、多个收款码、公章、公章位置和公章大小。
- 订单列表点击“销售单”会打开销售单抽屉，不离开当前订单列表。
- 销售单抽屉内可打开销售单设置抽屉。
- 销售单页面右侧客户信息抽屉可以保存客户公司名称、公司地址和联系电话。
- 销售单页面先展示预览，刷新预览不创建历史版本，确认生成后才创建新版本。
- 历史版本下载和下载最新版都能返回 PDF，不出现 `invalid document id`。
- 点击“确认生成图片”会生成 PNG 图片版本；历史图片和最新版图片下载都返回 `image/png`。
- 生成的 PNG 图片应保持文字清晰、行距正常，分享给微信时使用高清图片，文字会偏粗显示，收款二维码会比预览更大，便于客户扫码。
- 销售单设置页和销售单预览页都可直接拖动公章并保存坐标，点击公章内部开始拖动时公章不跳走，刷新预览后位置不丢。
- 销售单设置页“去除背景”会把当前公章转换为透明 PNG。
- 销售单预览和 PDF 都能看到自适应收款码、公账信息、公章和多行文本，客户公司地址不截断，公章盖在公司名称附近且不被拉伸。
- 公司设置公司名称未维护且客户公司名称为空时，生成 PDF 不报错，PDF 公司名使用客户名。
- 同一个订单第一次生成得到 V1，再生成得到 V2。
- 历史版本可以继续下载，最新版链接指向当前最新版本。
- 修改销售单设置或公章位置后，旧 PDF 和旧图片版本不被覆盖；重新生成 PDF 或图片才使用新设置。
- 生成 PDF 后点击“分享PDF到微信”会直接分享 PDF 文件；生成图片后点击“分享图片到微信”会直接分享 PNG 图片文件。
- 销售单 PDF、销售单图片和出库单 PDF 都通过统一 `/api/share-resources` 分享接口定位文件，并通过同一个前端 helper 分享文件。
