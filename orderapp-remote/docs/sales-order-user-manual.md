# 销售单用户手册

## 销售单设置

| 区域 | 操作 |
| --- | --- |
| 公司名称 | 在设置里的“销售单设置”维护，生成 PDF 时写入快照；这里可为空，生成时会按客户公司名称、客户名依次兜底。 |
| 个性化说明 | 用于包装、付款、售后等说明；只影响之后新生成的销售单。 |
| 收款方式 | 填写微信、支付宝、对公转账等文字说明。 |
| 收款码 | 可上传多个收款码，填写名称、说明和排序；生成 PDF 时会展示收款码图片。 |
| 公章 | 上传后用于销售单设置快照，生成 PDF 时会展示公章图片；后续重新上传不会改写旧销售单版本。 |

## 生成销售单

| 区域 | 操作 |
| --- | --- |
| 订单列表 | 每行“操作”列点击“销售单”进入该订单销售单页面。 |
| 客户信息 | 生成前点击“客户信息”，右侧抽屉可维护客户公司名称、公司地址、联系电话、联系人、收货电话和收货地址。 |
| 生成 PDF | 点击“生成销售单 PDF”，系统按当前订单和当前销售单设置生成新版本。 |
| 历史版本 | 同一订单重复生成会得到 V1、V2、V3；旧版本保留，最新版单独标记。 |
| 下载 | 可下载指定历史版本，也可下载最新版。 |
| 快照 | 已生成 PDF 固化当时的订单明细、金额、公司名称、客户公司信息、说明和收款信息。 |

## 验收检查

- 销售单设置可保存公司名称、说明、收款方式、多个收款码和公章，生成的 PDF 可看到对应图片。
- 订单列表能进入销售单页面。
- 销售单页面右侧客户信息抽屉可以保存客户公司名称、公司地址和联系电话。
- 销售单设置公司名称为空且客户公司名称为空时，生成 PDF 不报错，PDF 公司名使用客户名。
- 同一个订单第一次生成得到 V1，再生成得到 V2。
- 历史版本可以继续下载，最新版链接指向当前最新版本。
- 修改销售单设置后，旧版本不被覆盖；重新生成才使用新设置。
