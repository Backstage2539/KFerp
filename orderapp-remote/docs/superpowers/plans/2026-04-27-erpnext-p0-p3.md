# ERPNext P0-P3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a minimal ERPNext-style inventory and manufacturing backbone covering stock ledger visibility, batches, material receipts, FIFO consumption, adjustment documents, BOM versions, work orders, job cards, and batch costing.

**Architecture:** Add a dedicated `stock` DDD module for ledger, batches, material receipts, material batches, and adjustments. Keep BOM version rules in `bom`, and manufacturing execution in `production`; HTTP packages only bind requests and call application services. Vue/Vite receives new internal views for stock and manufacturing operations.

**Tech Stack:** Go, Echo, pgx/Postgres, Vue 3 + Vite, existing DDD module layout.

---

### Scope

- P0: Stock ledger and batch read APIs plus Vue views.
- P1: Material receipts, material batches, and FIFO batch consumption during production finish.
- P2: Stock adjustment documents and BOM version activation.
- P3: Minimal work orders, job cards, and production batch costing.

### Delivery Rules

- Write unit tests before domain/application logic.
- Write API/handler tests before new HTTP routes.
- Do not add SQL or transactions in business HTTP packages.
- Do not add server-rendered templates for user-visible pages.
- Keep this phase minimal: no approval workflow, accounting entries, permissions, print formats, or advanced routing.
