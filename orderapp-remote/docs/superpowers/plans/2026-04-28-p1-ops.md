# P1 Operations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver P1-A shipping closure, P1-B supplier purchasing, and P1-C account governance on top of the current ERP workflow.

**Architecture:** Keep shipping behavior in the sales module, purchasing in a new purchase DDD slice, and account governance in the authz/support boundary. Vue/Vite receives focused workbench pages and all user-facing workflow changes update source manuals and seeded PR/DEV/UT/API/REV rows.

**Tech Stack:** Go, Echo, pgx/Postgres, Vue 3 + Vite, Node test runner.
