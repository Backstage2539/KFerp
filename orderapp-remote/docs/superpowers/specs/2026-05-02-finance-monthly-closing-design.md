# 财务月结一期设计

日期：2026-05-02

## 背景

财务功能不能只按当前小规模纳税人业务定制。产品要服务不同咖啡 ERP 用户：咖啡烘焙厂、咖啡贸易商、咖啡壳豆加工厂和综合咖啡工厂，后续可扩展到鲜果加工厂等相似加工贸易场景。

第一版目标不是替代金税申报或完整总账，而是让经营者每月能在系统内看到收入、成本、费用、毛利、净利、税费估算，并把结账后的变更纳入受控调整。

## 范围

- 月度财务首页。
- 财务设置：企业类型、纳税人类型、税率参数、锁账模式。
- 费用录入：期间费用、主营成本。
- 月度经营报告：老板简报、利润表、税费估算、PDF/Excel 导出。
- 月度结账：默认强锁账。
- 结账后金额调整：收入、主营成本、期间费用、税费、其他。
- 权限：finance.read、finance.write、finance.close、finance.close_mode.manage。

## 税务口径

- 小规模纳税人：含税收入换算不含税收入，估算增值税；不含税收入低于免税阈值时增值税估算为 0；继续估算附加税和企业所得税。
- 一般纳税人：含税收入换算销项税额，扣减可抵扣进项，估算应交增值税、附加税和企业所得税。
- 企业所得税：先按标准税率估算，再在小微优惠开启且年化利润未超上限时使用小微有效税率，显示节税估算。
- 页面和导出都必须提示：税费为经营管理估算，不作为正式申报结果。

## 锁账

- 默认 `strong_lock`。
- 强锁账月份结账后，来源费用不能直接新增到同月；修正走调整。
- `light_confirmation` 作为试运行/早期客户选项存在，但切换入口只对白名单用户显示。
- 后端同时校验 `finance.close_mode.manage` 权限和应用服务白名单，不能只靠前端隐藏。
