# 用户权限与账号用户手册

## 操作要点

| 区域 | 操作 |
| --- | --- |
| 角色 | 在用户权限页为员工勾选角色并保存，菜单和 API 会按角色权限控制。 |
| 登录状态 | 在“账号”列切换可登录/已停用；停用后员工不能再登录，已有 Bearer 会话也不能继续访问。 |
| 重置密码 | 输入新密码并点击重置；密码至少 6 位，重置后账号自动恢复为可登录。 |
| 手机号登录 | 在 `/login` 输入手机号和密码，登录成功后系统会自动进入 Vue 工作台。 |
| 退出登录 | 在系统顶部点击“退出”，系统会注销当前登录会话、清除本机 token，并回到登录页。 |
| 审计 | 账号启停、密码重置和角色变更都会进入操作日志，便于追踪。 |

## 验收检查

- 管理员能为员工启用或停用登录。
- 停用员工使用密码或短信登录会被拒绝。
- 停用员工已有登录 token 不能继续解析为有效员工。
- 管理员重置密码后，员工可用新密码登录。
- 手机号密码登录成功后可直接进入系统并正常访问 API。
- 点击“退出”后返回登录页，当前会话不再继续使用。
